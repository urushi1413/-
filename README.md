# カウンター

自分ルールを破った回数を1日ごとに数えて、その分の罰（スクワットなど）を消化するアプリ。

- ルールごとに「破ったら何を何回」を決める（例: 顔を触らない → スクワット 10回）
- 「やっちゃった」をタップして +1。時刻も記録され、直前の1回は取り消せる
- 罰は 回数 × 1回あたりの量。消化しきれなかった分はツケとして翌日に持ち越す
- 記録: 30日の回数グラフ、違反ゼロの日、先週比、やりがちな時間帯
- 日付の切り替わりは朝4時（設定で変更可）。データは localStorage に保存、JSON でバックアップ

1回きりの「やる / やらない」はチェックリスト（to-do）側の担当。こちらは何度も起きることを数える用。

`index.html` をブラウザで開くだけで動く（ビルド不要）。
