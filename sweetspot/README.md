# SWEET SPOT

コンセプト：**打点と球種がちゃんと結果に効く、球足の速いリアル系テニス**

## ネットプレー（ボレー・スマッシュ）

### 球種ごとの許容幅

| 球種 | タイミング | 距離 | 高さ | リーチ |
|---|---|---|---|---|
| フラット | 0.8 倍（シビア） | 0.6 m | 0.6 m | ±0 |
| トップスピン | 1.0 倍 | 0.8 m | 0.8 m | ±0 |
| スライス | 1.3 倍 | 1.1 m | 1.0 m | +25 cm（片手で腕を伸ばして届く） |
| スライスロブ | 1.4 倍 | 1.1 m | 1.0 m | +30 cm |
| トップスピンロブ | 1.0 倍 | 0.8 m | 0.8 m | ±0 |
| ドロップ | 1.1 倍 | 0.9 m | 0.9 m | +10 cm |

足元の薄い輪（届く限界）は、溜めている球種に合わせて広がる。

### AI のネットプレー

- 甘い球をベースラインの 2m 以上内側で攻めたら、強気なほど前に出る（EASY 約 40%、PRO 約 70%）。ネットからボレーしたら、そのまま残る
- たまにサーブ＆ボレー（芝では多め）
- ネットでは自分が打ったコースの側に寄って、ネットから 2.6m で構える
- バウンド前のボレーを優先（早く触るほどいい）。高い球はスマッシュ。ロブで下げられたら（サービスラインより 3m 以上後ろ）ネットはあきらめる
- ボレーは届きやすいスライスで相手のいない方へ。高ければ叩く。相手が下がっていれば短いアングルかドロップボレー
- AI 同士の試算：ネットに出た選手がいたポイント 20〜25%、ネットに出た側がそのポイントを取る割合 51〜58%（現実のプロは約 65%）

| ショット | どう打つ | 速さ・決まりやすさ（打点の質 75%、PRO の AI 相手の試算） |
|---|---|---|
| ボレー | ノーバウンドで打つと自動。大きく振らない（自分の力 6 割）が、来た球の勢いを使う | 深いコーナーへ約 106km/h、決まる 70% |
| アングルボレー | ネットに近いほど短く狙える（I/、で深さ）。ネット前ならネットから 2.5m まで | 鋭い角度は柔らかく：Shift+K（ドロップボレー）＋ U/O |
| スマッシュ | 1.85m より高い球は頭上で打つ。J/L で叩く。ノーバウンドでもフルスイング | コーナーへ約 160km/h、決まる 98% |

## 空振りについて

現実では、プロはもちろん普通の人でも、ラケットに全く当たらない空振りはめったにない。ずれたら「芯を外す」。
人は振っている途中でもボールに合わせてラケットを微調整しているので、ゲームでもそうしている。

- 早く振っても 0.2 秒先までなら、ラケットがボールに合わせにいって当たる。ただし早かった分だけ当たりの質が落ち（0.3 秒早いと最低）、引っ張り気味になる
- 遅れても、体の真横より少し後ろ（-75°）までなら、押し出すように当たる（質はほぼ最低）
- 空振りになるのは、物理的に届かない球、大きく早すぎる、ボールが体の後ろまで行ってから振った、のどれか

普通の人（タイミングのずれ ±150ms）で試算：空振り 39% → 19%。タイミングが良い人（±40ms）は 0%。

## メニュー

起動するとタイトルメニュー。プレイ中は Esc で一時停止して同じ設定ができる（RESTART、BACK TO TITLE もある）。

| 項目 | 内容 |
|---|---|
| Mode | MATCH / RALLY / RETURN / SERVE |
| AI level | EASY / NORMAL / PRO |
| Style | REAL / CASUAL（簡単） |
| Court | HARD / CLAY / GRASS |
| Assist | 手がかり表示：TIMING + SPOT / TIMING / OFF |
| Practice feed | ラリー練習の球出し：PRO / CLUB |
| Mouse sensitivity | 0.25〜3.0 |

W/S で選ぶ、A/D で変える、Enter で決定。マウスなら左クリックで次、右クリックで前。
モードと AI を変えると、戻ったときに最初からやり直す。プレイ中のキー（G、1/2/3、N、H、V）も練習では今まで通り使える。
**試合の途中は G・1/2/3・N・V・F は効かない**（G で試合が消える事故があったため。お知らせ「試合中は変えられません」が出る）。変えるのは Esc → 選手と試合から。
試合の途中でスロー（T）・自動操作（B）を入れたり、メニューで難しさを変えたりすると「補助を使った試合」になり、結果の表の下に出る。売る版は試合中のスローなし、大会の試合中は自動操作なし。

## 操作（マウス）

手の置き方はマイクラと同じ。左手で WASD・Shift・スペース、右手でマウス。
マウスを動かすと視点ではなく「相手コートの狙いの印」が動く（カメラは後ろから固定）。カーソルはウィンドウに固定して隠す。

| 入力 | 動作 |
|---|---|
| WASD | 移動 |
| マウスを動かす | 狙い（相手コートの印）。奥に動かすと深く |
| 左クリック（押して溜め、離して打つ） | トップスピン |
| 右クリック | スライス |
| スペース ＋ クリック | フラット |
| Shift ＋ クリック | ロブ（左＝トップスピンロブ、右＝スライスロブ） |
| Ctrl ＋ クリック | ドロップ |
| サーブ | 左クリック＝キック、右クリック＝スライス、スペース＋クリック＝フラット。狙いはサービスボックスの中 |
| Esc | 一時停止して設定メニュー（もう一度 Esc で戻る） |

ロブもドロップも、どこに落とすかはマウスの狙いで自由に決める（短いロブ、深めのドロップも打てる）。

普通のショットは、ネットから 6m より短くは狙えない（ネットに近いほど短く狙える。ネット前なら 2.5m）。
キーボードの J/K/L（溜め）と U/O/I/、（狙い）も使える（マウスなしでも遊べる）。

キーはすべて 設定 → キー設定 で変えられる（移動・狙い・打ち分け・ロブ/ドロップ/フラットの押しながらのキー・かがむ・叩きつけ・リプレイ・消音）。
操作を選んで Enter かクリック、新しいキーを押す。ほかの操作が使っていたキーなら入れ替える。Esc・Enter・Tab・F1/F2/F12・1/2/3・G/B/H/N/V/F/T/C は
ほかの切り替えに使っているので割り当てられない。割り当ては sweetspot_settings.txt に `key_up=87` のように保存する（数字は raylib のキーの番号）

## 難易度（N で切替）

| | 本格（REAL） | 簡単（CASUAL） |
|---|---|---|
| 考え方 | 打点・タイミング・立ち位置がそのまま結果に出る | ボールの近くなら返る |
| 届く範囲 | 2.1m（スライド 2.4m） | +50cm |
| タイミング・距離の許容幅 | そのまま | 1.8 倍 |
| 当たりの質 | 0〜100% | 最低 35% |
| ぶれ | そのまま | 45%（サーブは 55%） |
| 早く離したとき | その瞬間に振る | 1 秒先まで、一番いい瞬間を待って振る |

AI には効かない（AI の強さは 1/2/3 で別に選ぶ）。友達と遊ぶなら CASUAL ＋ AI EASY がおすすめ。

普通の人（タイミングのずれ ±150ms、立ち位置のずれ 30cm）で試算：

| | 空振り | IN |
|---|---|---|
| REAL | 48% | 32% |
| CASUAL | 11% | 85% |

- 初めて起動した人（設定ファイルがない）は CASUAL（補助あり）から始まる。今まで遊んでいた人は保存された設定のまま
- CASUAL で（自動操作・スロー・難しさの切り替えを使わずに）試合に勝つと、結果の後の Enter で「ひとつ提案」：REAL に挑戦するか聞く（1 回だけ。断ると `hint_real=1` が保存されて、もう聞かない）。大会・バトルでは出ない

## コースの狙い（右手）

**左右はマウス、深さは押す長さ**で決める。

- ストローク：押した瞬間は球種の一番浅いところ（ネットから 6m。ネットの近くならもっと浅く角度をつけられる）。
  押し続けると深くなり、0.5 秒でベースラインの約 2m 手前。それ以上押しても深くならない（ボールを待つ間押していてもアウトにはならない）
- 強さも押す長さで上がる（6 割 → 10 割）。押さなくても 6 割の強さが出る。押している間も走る速さは落ちない
- 押している間、相手コートの印が奥へ動く
- 左右の狙いはサイドラインの約 0.25m 内側まで。ショートクロスやライン際も狙える。
  ただし約 1.2m 内側より外はライン際で、印の動きが重くなり（マウスの 35%）、印が橙になる。うっかりは行かないが、狙えば行ける
- REAL でも、当たりが良ければ横アウトを補正する（自分の打球だけ）：質 30% から効き始め、65% 以上なら横には出ない（サイドラインの 5cm 内側に収める）。当たりが悪いと今までどおり出る
- CASUAL は横にアウトしない：実際に落ちる所を計算して、サイドラインの 25cm 内側に収まるように向きを直す。
  印はサイドラインの約 0.5m 内側まで動かせて、重くもならない（長さのアウトとネットはある）
- サーブ：左右はマウス（サービスボックスの中）、深さはトスを上げてから離すまでの時間。
  0.30 秒で浅い（ネットから 4m）、0.60 秒でサービスライン、それより遅いとロング。トスの一番上（0.46 秒）で打つと 1m 手前、
  深く入れるには一番上を少し過ぎてから打つ

以下は以前の説明（キーボードの狙い）：

| キー | 狙い |
|---|---|
| U / O | 左 / 右 |
| I / 、（カンマ） | 深く / 短く |

何も押さなければ真ん中の深め。コースはマウスの印で決まる。タイミングのずれ（早い＝引っ張り、遅い＝流れる）は ±30ms を超えた分だけ効く（100ms ずれて約 2°＝向こうのベースラインで約 0.9m。CASUAL では半分）。

コースは手首（面の向き）で保てるので、打点がずれても左右はあまりぶれない。打点のずれは主に深さ（ネット・アウト）と球の勢いに出る。
当たりの質ごとの左右のばらつき（標準偏差）：質 20% で 1.5m、40% で 1.0m、60% で 0.6m、85% で 0.3m。
自分の打球が落ちたら、狙った場所と落ちた場所を線で結ぶ（1m 以内は緑、2.5m 以内は黄、それ以上は赤）。
サーブは離した瞬間の A/D または U/O で左右、W/S または I/、で深さ。

## 走る・滑る

- 加速 9 m/s²、ブレーキ 20 m/s²（全速から 0.9m で止まる）。押している（テイクバックしている）間も同じ速さで走れる
- **スライド**：溜めながら 3m/s より速く走っていて、方向キーを離す・逆に入れると自動で滑る。
  滑りながら打てるので、止まる時間がいらない。滑っている間は低く広い構えになり、リーチが 30cm 伸びる（2.4m）。
  減速は 7 m/s²（全速から約 2.6m 滑る）。AI も同じように滑り込む
- それでも届かなければ、足と腕を伸ばしきって取る（2.6m まで）。それも届かなければ、走っている勢いで飛びつける（2.8m まで）

## 体の動き

- 足は股関節・膝・足首、腕は肩・肘・手首で曲がる（2 本の骨の長さから関節の位置を計算）
- 構え：足を広げて膝を曲げ、腰を落とす。左手はラケットの首に添える
- 走る：走る向きに合わせて足を交互に踏み出し、足を上げる。腕は足と逆に振る。速いほど前傾して、腰が上下に弾む
- 打つ：構えで肩を横に向け（フォアは右、バックは左）、振りながら前へ戻す。肩の線が回るのが見える。
  フォアの構えでは左手で球を指し、振っている間は左手を体に引きつける
- サーブ・スマッシュ：トスの間は膝を深く曲げて後ろに反り、左手を上げる。打つときに伸び上がって跳び、前へ倒れ込みながら右足を後ろに蹴り上げる
- トップスピン・フラットドライブの振り方：構えから一度ラケットを球の下へ落とし（ラケットダウン）、下から上へ振り抜いて反対の肩の上で終わる。
  振り出しは手が先に出てラケットの頭が遅れ、当たる瞬間にそろい、振り抜くと頭が追い越す（手首のしなり）。面は振り抜くほど伏せる
- 滑り込みは膝を曲げて、片足を大きく開く
- 構えると横を向く：肩はストロークで 75°、サーブ・スマッシュでほぼ真横（90°）、腰はその 6 割。前足（フォアなら左）を踏み出し、後ろ足を引いて、つま先も横を向く。
  サーブでは左足のつま先を右前のポストへ、右足はベースラインと平行に置く
- 膝：構えでは腰を 10cm 落として膝を曲げておく（脚の長さ 0.88m）。ストロークで引くとさらに 7cm 沈み、振りながら脚で押し上げる。しぐさの間は膝を伸ばす
- 走り：振り出す足は膝を上げ、後ろへ蹴った足はかかとを上げる。腕は肘を曲げて足と逆に振り、ラケットは立てて持つ（右腕は左足と一緒に前へ）。
  横へゆっくり動くときは、足を交差させずに横へ跳ねる（サイドステップ。体はネットを向いたまま、両手でラケットを持って低い姿勢）。
  横へ速く（3.5m/s 以上）走るときは、体を走る向きへ回して走る。打つ構えに入ったら正面へ戻す
- 跳んで伸びて取る（体から 1.35m より遠い球）：球の方へ跳び、体を倒して足を大きく開く

### 見た目

- 陰影：選手・審判・観客席の部品（筒・球・箱）は、光の向き（左上前の太陽）から面ごとに明るさを変えて描く（一色ののっぺりした見た目にしない）
- 足元に影を落とす。空は上ほど濃い青。ネットに網目。芝はベースラインのあたりがすり切れて土が見える

- 服：半袖のシャツ（胸は横に広く、ウエストで細い）、太ももの半分までのショーツ、白いソックスとシューズ。首と髪もある。
  選手ごとにショーツと髪の色が違い、フェデラーは白いヘッドバンドとリストバンド、ナダルはバンダナ
- ラケット：楕円の枠、のど（V 字）、グリップ、ガット
- 振り方は「手の位置」と「ラケットの向き」を別々に動かす。腕とラケットが一本の棒にならず、
  ラケットを立てて引く → 頭が背中側に落ちる → 下から前へ振り抜く → 肩の上に巻きつける、がなめらかにつながる（キーの間を曲線でつなぐ）
- フォア：肩を入れてラケットを立てて引き、左手を伸ばして球を指す。振るのに合わせて左手を胸に引きつけ、左肩の上で終わる
- 片手バック：左手でラケットの首を支えて肩を大きく入れ（95°）、振り出しで左手を離す。腕を伸ばしたまま高く振り抜き、左手は後ろへ（両腕を広げて終わる）。肩は開ききらない
- 両手バック：左手を添えて、右肩の上で終わる
- スライス：ラケットを肩より高く引いて面を開き、上から斜め下へ前に長く運ぶ。片手で、左手は後ろへ
- 優雅さ（フェデラーが一番）：フォロースルーが高く大きく、最後まで振り切る
- サーブ：構えでは横を向いて立ち、ラケットの先をサービスボックスへ向け、ボールを持った左手をラケットののどに添える。
  トスで、ラケットは振り子のように下から後ろへ回り、左腕は伸ばしたまま真上へ（ボールを指して待つ）。肘を肩の高さに上げてラケットを立てる（トロフィー）。
  振るとラケットの頭が背中に落ち（ラケットダウン）、腕を伸ばしきってほぼ真上で当て、手首を内側にひねって（プロネーション）、左の腰の横で終わる
- ボレー：構えでは左手でラケットを支え、ラケットの頭を立てたまま肩の横へ小さく引く（手首を後ろへ返す。大きく引かない）。
  当てるのに合わせて、球と反対の足（フォアなら左）を球の方へ踏み込み、左手を離してバランスを取る（フォアは前へ、バックは後ろへ）。
  体の前で当てて、前へ 20cm ほど短く押し出し、面を相手に向けたまま止める（振らない）。
  低い球は膝を曲げて沈み、面を上に開いて、ラケットの頭はなるべく落とさない。肩はあまり回さない（フォア 30°、バック 45°）
- スマッシュ：上がった球が来ると横を向き、振り子なしでラケットを真上へ担ぎ上げ（トロフィー）、左手で球を指す（AI も構えを見せる）。
  振るとラケットの頭が背中に落ち、体の前で高く当てて、上から叩き下ろす。後ろ足で踏み切って跳び、空中で脚を入れ替える（シザースキック）。高い球ほど高く跳ぶ
- スプリットステップ：相手が打つ（サーブも）たびに、小さく跳んで、足を広げ膝を曲げて着地する（走っている間は小さく）
- ナダルのフォア（投げ縄）：ラケットを高く引き、膝の下まで深く落として、下から真上へ一気に持ち上げる。
  肘を高く上げて、打った側の頭の上で振り終える（反対の肩に巻きつけない）。オープンスタンスで沈み込み、振り上げと一緒に体ごと跳び上がる

## スライスの曲がりと振り方

- スライス系（スライス・スライスロブ・ドロップ）は逆回転に加えて横回転がかかる（スライスは逆回転の 8 割、ロブとドロップは 5 割弱）。
  右利きなので、フォアは右、バックは左へ曲がり、弾んだ後も同じ向きに滑る
- 曲がる分を見込んで打ち出すので、落ちるのは狙いの印のところ。途中で 0.3m ほど膨らんで見える
- 横回転があると球の浮きが減るので、打ち出し角は横回転込みの弾道で決め直す（狙った深さに届き、ネットの上に 10cm の余裕）
- 振り方：ラケットを肩より高く引いて面を開き、上から下へ切って、前に短く押し出す。バックのスライスは片手

## 名前

- 「自分」「YOU」とは出さない。使っている選手の名前（例 NADAR）、癖なしの選手のときは設定の「名前」に入れた名前（英数字 12 文字まで、最初は PLAYER）を出す
- スコア表、テロップ（例 URUSHI winner）、試合の結果、組み合わせ表、ADVANTAGE のコールなど。相手も「AI」ではなく相手の名前

## 抗議・ラケット破壊・看板

- 抗議（文句）：審判台の前まで歩いていき、審判の方を向いて両手を広げて文句を言う
- X：自分もラケットを叩きつけられる（ポイントの間）。ブーイングされる代わりに「燃える（FIRED UP）」：数ポイントの間、足が速く・球が強く・サーブが速くなるが、ミスも増える。
  強さは叩いた直後がいちばんで、1 ポイントごとに 4 割ずつ弱まる（画面の左に燃え具合の棒）。
  1・2 回目は「行為違反、ラケットの乱用。警告」（2 回目は最後の警告）、3 回目からはポイントペナルティ（相手のポイント）
- 奥の壁に架空の広告看板（ACE WATER、TOPSPIN BANK、DEUCE MOTORS、SLICE AIRWAYS）と、真ん中に最後のサーブの速さを出すスピードメーター

## サーブの難しさ（実際の記録から調整）

- 遊んだ記録では、自分のファーストサーブが 87% 入っていた（プロは 60〜65%）。速く打っても入る率がほとんど落ちず、キックは 158km/h で 92% 入っていた
- 速いサーブほどぶれる（125km/h を超えた分）：全力のフラットは 5 割、スライスは 6 割ほど。ファーストのフラットとスライスは 6 割前後
- キックは遅く（95〜145km/h）高く弾む：安全に入る（全力で 86%）セカンド向き
- 速いサーブ・体から遠いサーブは、レシーバーが返せない（当てられない・枠に当たる）ことがある。NORMAL 相手のファースト（フラット）は 6% が返されず、26% は返球がミス（前はどちらも 0〜1% と 18%）
- AI のサーブは安定感とコースを別に決めているので、速さのぶれは弱く効く（NORMAL のファーストの確率 59%）

## タイトルとメニュー

- タイトル：今選んでいる自分と相手がコートでボールをついている。項目は「プレイ（←→でモード）・グランドスラム・選手と試合・設定・クレジット・終わる」
- クレジット：制作、録音（作者が会場で録った音・作者の声）、効果音素材（Gregor Quendel の CC BY 4.0 の作者名とリンク、Kenney・OpenGameArt の CC0）、
  合成した音、フォント（IPA フォントライセンス）、raylib、「選手・大会・トロフィーは架空のもの」のおことわり。音の出典の細かい一覧は sounds/CREDITS.txt
- 選手と試合：モード・ツアー・自分の選手・相手・AI の強さ・コート・試合の長さ・難しさ。右に 2 人が立ち、名前・身長・紹介が出る
- 設定：手がかり・狙い方・マウスの感度・練習の球出し・音・画面の表示・ガイド・言語
- 時間帯と天気（「選手と試合」のページ）：時間帯は おまかせ / 昼 / 夕方 / ナイター、天気は おまかせ / 晴れ / くもり。
  おまかせは試合ごとに決まる（昼 5・夕方 2・ナイター 3、晴れ 7・くもり 3）。空の色、全体の色合い、光の向きと強さが変わる。
  夕方は夕日（低い光とオレンジの空）、くもりは影が弱い、ナイターは暗い空（晴れなら星）と、観客席の上の壁に並んだライトがコートを照らす
- 一時停止（Esc）：続ける・選手と試合・設定・やり直す・タイトルに戻る・終わる。Esc で前のページに戻る

## いい当たり・怒りのしぐさ・ロブとドロップ

- 当たりの質が 80% 以上（サーブは 88% 以上）だと、打った点から金色の光が放射状に飛び、輪が広がり、軌跡が金色になり、画面の縁が一瞬光る
- 怒りのしぐさ：ラケットを前の地面へ投げつける（手を腰に当ててうつむく）、ポイントが終わった球を観客席へかっ飛ばす。
  キルギオス（両方）、マレー・ズベレフ（投げる）、ジョコビッチ・メドベデフ・サバレンカ（かっ飛ばす）
- ロブ・ドロップは打つ形からは読めないので、AI が気づくのが遅れる（0.2 秒前後）。AI は後ろへ下がるときに遅い（体の向きを変えて走るので）。
  ベースラインの後ろの NORMAL にドロップを打つと 24% は届かない（前は 4%）、ネットの NORMAL の頭上を抜くロブは 39% 届かない（前は 5%）

- 芯の手応え（設定 → 芯の手応え、初めはあり）：芯（質 80% 以上）で捉えると、0.045〜0.08 秒だけ時間が止まり（ヒットストップ）、画面が 0.16 秒小さく揺れる。サーブは質 88% 以上。打球音も少し大きく高く。自動操作では起きない。揺れが苦手なら「なし」

## ジャンプ

- ふつうでは届かない高い球（3.05m を超えて 3.45m まで）は、自動で思い切り跳んで頭上で打つ（AI も）。空中なので当たりは少し不安定
- 高い球ほど高く跳ぶ（最大 0.6m）。肩より高い球をストロークで打つときは、跳びながら打つ

## 試合に勝ったとき

- 自分が喜ぶ（膝をつく・両手を上げる・跳んで拳・ラケットを掲げる）。相手はがっくり（頭を抱える。メドベデフは手を広げるだけ）
- 大歓声（拍手を重ねていつもより大きく）と紙吹雪。文字は出さない。4.5 秒ほどしてから試合の統計
- 声と歓声は sounds/ に置くと鳴る：自分の喜ぶ声は you_celebrate（自分の選手を選んでいればその選手の名前、例 nadar_celebrate）、試合に勝ったときの歓声は match_win（_2、_3… で複数）
- 相手が勝ったときも、観客は自分が勝ったときと同じ大歓声で沸く（観客はどちらの味方でもない）。紙吹雪は自分が勝ったときだけ

## 的あて（60 秒）（タイトルの「プレイ」で ←→）

- 相手（球出し）が球を出し、自分が打ち返した球の最初に弾んだ所と、相手のコートの的の中心の距離で点が入る。相手は打ち返さない。的は 1 球ごとに変わる（7 か所：深い左・右・真ん中、短いアングル左右、中くらい左右）
- 点：0.6m 以内 100（ど真ん中！）、1.2m 以内 50、2.0m 以内 20、それ以外でイン 5、アウト・ネット・空振り・見送りは 0
- 20 点以上が続くと倍率：1 回ごとに +0.25、最大 2 倍。0 点・5 点で連続は 0 に
- 時間は最初の球を出したときから 60 秒。時間切れの後は球を出さない（飛んでいる球は数える）。終わったら点・自己ベスト・内訳。Enter でもう一度
- 記録を比べられるように、球出しは「クラブ」に固定（挑戦をやめたら元に戻す）。自己ベストは記録に残る（スローを使ったときは数えない）

## 練習の相手

- ラリー練習・リターン練習でも、選んでいる相手の選手が向こうのベースラインに立ち、球を出すたびに打つ（リターン練習はサーブ）

- ラリー練習：画面の上の真ん中に「ラリー ○」（このラリーで自分が入れた数）と「自己ベスト ○  前回 ○」。10・20・30・50・100 本ごとに金色で大きくなり、観客がどよめく。5 本以上で自己ベストを超えると「新記録！」（記録に残る）。球出し（V）・モード（G）・やり直しで 0 に戻る

## リターン練習（試合と同じサーブ）

- 相手のサーブは、試合の AI のサーブと同じ処理（`AiServePrep` → トス → `AiServe`）。前は別の「サーブマシン」で、速さもリズムも試合と違っていた
  - 速さ・回転・コース・安定感は AI の強さ（1/2/3 で切り替え）と選手の癖で決まる。ファーストがフォルトならセカンド（キック）。ダブルフォールトもある
  - デュースサイドとアドサイドを交互に。左利きの選手は左で打つ。背の高い選手は高い打点から
  - サーブ前の儀式（選手ごとのボールつきなど）→ 0.15〜0.45 秒 → トス → 0.52 秒で打つ。設定でボールつきをなしにすると、構えて 1.2〜2.2 秒でトス
- 声：サーブの前の声と当たる音、フォルト・アウトのコールは試合と同じ。スコアコールはしない
- 立つ位置：試合で AI がレシーブするときと同じ本来の位置（センターから約 3.2m、サーバーの立ち位置に合わせる。セカンドは前へ）。始めた瞬間からその位置
- テロップ（「ace」など）とスコア（真ん中の 15-0、右上のスコア表）は出さない。右上には相手のサーブの速さだけ。デュース／アドの左右とセカンドサーブを決めるために、点数は中で数えている
- 試合と違う所（わざと）：ラリーにはしない（相手は打ち返さない。リターンだけをくり返すため）、観客はいない（拍手・「お静かに」はない）

## レシーブの立ち位置

- AI は、こちらのサーブの立ち位置に合わせてレシーブの位置を変える。打てるコースの両端（センターの T とワイドの角）を結ぶ角の二等分線の上に立つ
- ワイドとセンターのサーブが同じくらい効くように：AI はセンターから 3.2m 外（レシーバーが打つ深さで、センターの球とワイドの球の真ん中）に構える。
  さらに、速いサーブで横へ大きく動かされると、追いついても慌てて振って返し損なう（センターでもワイドでも同じ）。
  入ったファーストのフラットでサーブ側が取る割合：NORMAL 相手でセンター 39〜40%・ワイド 38〜45%（前はセンター 26〜29%・ワイド 45〜49%）、
  PRO 相手でセンター 20〜28%・ワイド 23〜30%（前は 11% と 28〜37%）。デュースサイドのワイドへのスライスは今も一番効く（実際のテニスでも定番）。
  人間がレシーブするときの最初の位置は今までどおり
- サイドライン寄りからワイドを狙うと、その分 AI は外へ動いて待つ（サーブ前にこちらが横へ動くと、AI も歩いてついてくる）
- 前は位置が固定で、サイドライン際からのワイドはほとんど返せなかった（NORMAL で 0〜1%）。今は 95〜100% 触る

## 選手らしさ：しぐさと気持ち（リサーチに基づく）

- **サーブ前の儀式**（AI がサーブするとき。大事なポイントほど長い）
  - ジョコビッチ：ボールを何度もつく（ふつう 8〜13 回、大事なポイントで 14〜19 回）
  - ナダル：後ろのパンツを引っぱる → 肩 → 反対の肩 → 鼻 → 耳 → 鼻 → 反対の耳を触ってから、ボールをつく。ポイントの間にもやる
  - フェデラー：髪を耳にかけて、2〜3 回つくだけ（速い）。シフィオンテクも髪を耳にかける
  - シャラポワ：後ろを向いてガットを直してから振り向く。ポイントの間もよく後ろを向く
  - キルギオス：1〜2 回だけですぐ打つ。相手がずっと後ろにいると、たまにアンダーサーブ
- **プレッシャー**（勝負強さ：大事なポイントでのタイミング・反応・ミス・サーブ）
  - 強い：ジョコビッチ、ウィリアムズ、ナダル、シャラポワ、アルカラス、シナー
  - 弱い：キルギオス
  - ズベレフ：長くプレッシャーに弱いと言われた（グランドスラム決勝 3 連敗）が、2026 年に全仏と全米を取って克服。
    勝負強さはふつう以上にしたが、大事なポイントのセカンドサーブのぶれと、崩れやすさが少しだけ残る
  - サバレンカ・ガウフ：大事なポイントのセカンドサーブでダブルフォールトが増える
  - 錦織：最終セットに強い（最終セットの勝率は歴代 3 位の 72.5%）。ジョコビッチ・ナダル・シャラポワも最終セットに強い
- **崩れる**：大事なポイントやセットを落とすと、しばらくタイミングと足が乱れて凡ミスが増える（メドベデフ、キルギオス、サバレンカ、ガウフ、マレー。ズベレフは少しだけ）。ポイントごとに戻る
- **気持ちが切れる**：キルギオスは先にセットを取られると、足が止まりミスが増える
- **しぐさ**：ジョコビッチとアルカラスは耳に手を当てて観客をあおる。メドベデフは勝っても手を少し広げるだけ
- **顔と表情**：目・眉・鼻・口・耳がある。吠える・拳を握ると口を大きく開け、文句を言う・ラケットを叩きつけると眉を寄せて怒る、喜ぶと笑う。打つ瞬間は声に合わせて口が開く。顔はネットの方を向き、天を仰ぐ・うつむくのにも合わせて動く
- **体つき**（選手ごと。身長とは別に、肩幅・胴の厚み・腕の太さ・脚の太さ・腰回り）：ナダルは筋肉質で腕が太い、キルギオス・ウィリアムズ・サバレンカは肩幅が広く力強い、
  アルカラスはがっしりして脚が太い、シナー・メドベデフはひょろりと細い、ジョコビッチ・ズベレフ・シャラポワ・ガウフは細身
- **顔の形と目の色**（選手ごと、写真の見た目から）：頭は縦長さ・横幅・あごの張りを変えただ円で、鼻の長さも違う。
  メドベデフはとても面長で細い、ナダル・キルギオス・ウィリアムズはあごが張る、錦織・バーティは丸め、フェデラー・ジョコビッチは鼻が高い。
  目の色：青（マレー、シナー、ズベレフ）、灰色がかった青（メドベデフ）、緑・緑がかったヘーゼル（シャラポワ、ジョコビッチ、サバレンカ）、ヘーゼル（シフィオンテク、バーティ）、茶・こげ茶（ほかの選手）。
  目は横長で、虹彩（目の色）・瞳・光の点があり、まぶたの線は細い
- **髪型・ひげ・かぶりもの**（選手ごと）：フェデラーとズベレフは横に流した髪、シナーはもじゃもじゃの赤毛、アルカラスとマレーは短い巻き毛、
  キルギオスは横を刈り上げてひげ、錦織は立てた短髪、ナダルはバンダナ（後ろに結び目が垂れる）からはみ出す髪、ジョコビッチとマレーは無精ひげ、
  ウィリアムズとガウフはまとめ髪（お団子）、シフィオンテクはキャップ、シャラポワはサンバイザー、ほかの女子はポニーテール
- 自分が選手を使うとき（Play as）も、勝負強さ・最終セットの強さ・大事なポイントのサーブのぶれはそのまま効く

## 当たりの説明（設定 → 当たりの説明）

- かんたん（初め）：左上に 3 行まで。見出し（芯！／まずまず／芯を外した ＋ 質の %、空振りなら空振りの理由）、直すこと 1 つ（言葉で）、結果（イン・アウト・ネット）

## 売る版（make SALE=1）

自分用の版（make）とは別に、売る・配るための版を作れる（sweetspot_sale）。実在の選手・大会と結びつく部分を架空のものにする：
- 選手の名前（例 Rogerr Federerr → Julien Varenne、Rafa Nadar → Leon Duvall）。ai.c の PN("自分用", "売る版") で切り替える
- 身長を表示しない。紹介文から本人を思わせる言葉（クレーの王者、独り言が多い、198cm など）を外す
- 決まったルーティン（儀式・髪を耳にかける・ガットを直す）はなく、ボールをつくだけ。耳に手を当てる・ハートのしぐさは、ふつうの喜び方に
- 大会名と場所を架空に（SOUTHERN OPEN / RED CLAY OPEN / GREEN LAWN CHAMPIONSHIPS / CITY LIGHTS OPEN、ハーバーシティ・オールドタウン・リバーサイド・メトロシティ）
- 芝の大会のトロフィーは、ふたと飾りのない金色の杯（女子も大皿ではなく杯）
- 見た目（髪型・体つき）はそのまま。ストアのページや宣伝では実在の選手名を使わないこと
- 開発用の記録（playlog.csv・matchlog.csv）は書き出さない。選手の声のファイルは番号の名前（v01〜v16）で読む
- `make dist`：売る版を作って dist/SweetSpot に exe・音（声のファイル名は番号に）・フォント・CREDITS.txt・遊び方（README_JA / README_EN）をまとめ、zip にする
  （Windows は dist\SweetSpot_Windows.zip。exe は必要な部品を中に入れ、コンソールの窓を出さない）。配る文書は dist_files/、ストアの文章と販売の手順は dist_files/STORE_PAGE.md

## ネットイン・レット・コートチェンジ

- ネットの白帯をかすめた球は、勢いがほとんど消えてふわっと上がり、相手のコートに落ちる（ネットイン）。深く当たった球は止まる
- サーブがネットインして入ったらレット：同じ番目のサーブ（1st なら 1st）を打ち直す。サーブの約 1.3%（実際とほぼ同じ）
- コートチェンジ：奇数ゲームの後（セットの終わりも、そのセットのゲーム数が奇数なら）。中継のような横からのカメラで、両選手が審判台の横のベンチへ歩き、
  （1 ゲーム目の後以外は）休み、画面が一瞬暗くなる間に審判台とベンチが反対側になって、自分の位置へ戻る。Enter で飛ばせる

  - 最後：ブランチ（`claude/` は省く）

## ルール（設定 → ルール）

試合のルールの一部を、あり／なしで変えられる（保存される）。

| ルール | あり（はじめ） | なし |
|---|---|---|
| ネットタッチ | ポイント中に体がネットに触れる、または打つときラケットがネットを越えると失点 | ネットで止まるだけ |
| ボディショット | 生きている球が体に当たったら打った方のポイント | 球は体を通り抜ける（前と同じ） |

- バトルモードのボディショットは、設定に関係なくいつもあり
- 数字は game.h の `NET_BODY_R`・`NET_RACKET_R`・`NET_AI_KEEP`・`BODY_HIT_R` など

### ネットタッチ（文字どおり触れたら）

- 選手はネットをすり抜けない。体がネットに触れた所（体の中心がネットから 20cm）で止まる
- 失点になるのは、ポイント中に次のどれかが起きたとき
  - 走ってネットまで来て、体がネットに触れた
  - 伸びて取った体（腰）がネットに届いた（真正面の球へ深く伸びたとき。横へ伸びるだけなら触れない）
  - 打つとき、ラケットがネットを越えた（球がネットから 13cm より近い所で打った）
- テロップは「○○ net touch」「○○ racket over the net」、記録の end_kind は `net_touch`
- AI（自動操作も）は走ってネットに近づかない（45cm で止まる）。伸びて取る・ネット際で打つときは、AI もネットタッチになることがある

## ボディショット（体に当たったら、打った方のポイント）

現実のルールどおり、生きている球が相手の体・服に当たったら、打った方のポイント（試合・バトル・リターン練習）。設定 → ルールで、なしにできる。

- ノーバウンドなら、アウトになる球でも当たったら失点（コートの外に立っていても）。よけるか、打つ
- 1 バウンド目がインの後に当たっても失点。1 バウンド目がアウト・ネットなら、もうポイントは終わっている
- サーブも同じ：バウンド前にレシーバーに当たればサーバーのポイント（フォルトになる球でも）。ネットに触れたサーブが当たったらレット
- 体は足元を中心にした円柱（半径 24cm、高さ＝身長）。腕とラケットは入れない（ラケットに当たったら打ち返したのと同じ）。Q でしゃがむと 35% 低くなる
- 振ろうとしていたら（押している・振る瞬間を待っている）、体に来た瞬間に振って、体の前で詰まって打つ。当たらなければ体に当たった
- AI も同じ。見送るアウトの球が体に向かってくるときは横へよける
- 当たると鈍い音と観客の「おお」、当てた方が手を上げて謝る。統計はウィナーに数え、試合の記録（matchlog.csv）の end_kind は `body_shot`
- バトルモードは今まで通り、当たる範囲が広い（腰から頭、半径 40cm）。詰まって打つことはせず、当たった方は倒れる
- AI 同士（`make sim`、各 300 ポイント）で、ボディショットで終わるポイントは 0〜1.3%

- ←→ で大会を選ぶ：AUSTRALIAN OPENN（ハード、メルボルン）、ROLAND GARROZ（クレー、パリ）、WIMBLEDONN（芝、ロンドン）、US OPENN（ハード、ニューヨーク）、
  SEASON: ALL 4（4 大会を続けて回る。全部取ると「CALENDAR GRAND SLAM」）
- 16 人の勝ち抜き：4 回戦 → 準々決勝 → 準決勝 → 決勝。メニューで選んでいるツアー（MEN / WOMEN）、試合の長さ、AI level で行う（コートは大会で決まる）
- 出場者はそのツアーの選手全員と自分。残りの枠は予選上がり（架空の名前、強さはばらばら。癖なしの AI）
- シード：3 つのコートの強さの平均で上位 4 人。1 シードは一番上、2 シードは一番下、3・4 シードは準決勝まで 1・2 シードと当たらない位置（くじ）。自分はシードなしで、7〜10 番目のどれか（くじ）
  - 自分の初戦（4 回戦）はシードなし、準々決勝で第 3 か第 4 シード、準決勝で第 1 か第 2 シードと当たる（山場が後ろ）。前は 8 シードで、初戦の相手が必ずシードだった
- 相手の強さはラウンドごとに変わる：選んだ AI の強さと隣の強さの間を補間する（4 回戦 -0.5、準々決勝 -0.2、準決勝 +0.15、決勝 +0.35）。EASY より下・PRO より上には伸ばさない（EASY の 1 回戦と準々決勝は EASY のまま、PRO の準決勝と決勝は PRO のまま）。組み合わせ表の「次」に（やさしめ）（手ごわい）と出る。ふつうの試合は変わらない

## リプレイとハイライト（試合のとき）

- 試合中は、球と両選手の位置・動きを毎フレーム記録している（最後の 25 秒）
- ポイントが終わったら **R** で、そのポイントをスロー（半分の速さ）で見直せる。テレビ中継のような横からのカメラが球を追う。**C** でカメラを切り替え（横から・自分の後ろから・ボールを追う・相手の後ろから）。Enter / R で戻る
- 見応えのあるポイントは自動でハイライトに取っておく（6 つまで）：長いラリー、ウィナー、エース（速さ付き）、大事なポイント、喜ぶしぐさ、ラケット破壊、試合の最後のポイント
- 試合が終わったら、統計の画面で **R** を押すとハイライトを順に流す（説明の字幕付き。Enter で次、Esc でやめる）

## 観客席と審判（試合のとき）

- コートの両横と奥に、段々の観客席（9 段、約 1,700 人）。カメラとコートの間に来る側の席は描かない（視界をふさがないように）
- 観客は 1 人ずつ形がある：頭・髪（色いろ、長い髪、坊主）・目・眉・鼻・口、キャップやつば広の帽子、サングラス、肩・腕（膝の上）・脚。
  体格・肌の色・服の色もばらばら。席ごとに 1 つの 3D モデルにまとめて描くので軽い
- ポイントが終わると観客が沸く：長いラリー・ウィナー・大事なポイントほど、たくさんの人が両手を上げて拍手する。だんだん落ち着く
- 審判台：ネットの横（左）。審判は明るいブレザーと帽子で座り、頭で球を追う
- 線審：両方のベースラインの後ろと、横の壁際（ベースラインとサービスラインの延長）の椅子に座る。
  アウト（サーブのフォルトも）のときは、球に一番近い線審が立ち上がって右腕を横へ伸ばす
- ボールキッズ：ネットの両端にしゃがむ

## 効果音

録音ファイルを `sounds` フォルダから読み込んで鳴らす（audio.c）。ファイル名と鳴る場面は `sounds/README.txt` に書いてある。
ない音は鳴らさないので、ファイルがなくてもゲームはそのまま動く。

- 打球音は当たりの質で 4 種類（芯・まあまあ・外した・フレーム）とスライス、サーブを使い分ける。強く打つほど大きい
- バウンド音はコートで変える。ネット、空振り、足音、観客のざわめき、拍手（ラリーが長いほど・ウィナーほど大きい）
- 同じ名前に _2, _3, _4 を付けたファイルを置くと、毎回その中からランダムに選ぶ。音の高さも毎回少しだけ変える
- 遠い音（相手の打球など）は小さい。メニューの Sound volume で音量、M で消音
- 使う音は、配布してよい許可（CC0 など）があるものだけにする
- 観客：「おお〜」（惜しいアウト、長いラリーの終わりのミス、ダブルフォールト）。ざわめきは 2 種類を交互に、ポイント中は小さく。ブーイング（叩きつけ・投げる・球をかっ飛ばす・審判に詰め寄る）
- 勝利の歓声は録音の盛り上がる直前から切り出して、1 秒以内に最高潮にする
- ラケットは約 1.2 秒おきに 5 回、振りかぶり直して叩きつける。鋭い「バキッ」は実際の音の特徴だけをまねて合成（`python3 tools/gen_racket.py`）。録音は使わない
- 主審のスコアコール：「フィフティーン・ラブ」などの言い回しごとの録音（call_15_0 など）、デュース、アドバンテージ、試合の終わりの「ゲーム・セット・アンド・マッチ」。
  会場のスピーカーを通した音に加工してある（`python3 tools/umpire_calls.py <録音フォルダ>`）。言い回しの録音がないスコア（ラブ・フィフティーンなど）は言わない
- アウトのコール：ふつうは電子判定（スピーカーから流れる声）。クレー（ローランドギャロスなど）は電子判定ではなく、線審が叫ぶ（加工していない声）
- 素材は Kenney（CC0）・OpenGameArt（CC0 / CC-BY）から、聞き比べて選んだもの。出典は `sounds/CREDITS.txt`。作り直しは `python3 tools/build_sounds.py <素材フォルダ>`、ブーイングと「おお〜」は合成（`python3 tools/gen_crowd.py`）

## AI の球速とコース

- AI は当たりの質で実際の速さが少し落ちるのを見込んで、高めに狙う（トップスピン 132＋30×強気さ km/h、フラット 145＋40×強気さ、スライス 88＋22×強気さ）
- **凡ミス（打ち損じ）**：楽な体勢のラリーの球でも、たまに芯を外す（当たりの質 35%、ぶれ 2 倍）。
  1 球あたり EASY 12%・NORMAL 9%・PRO 7%、決めにいく球はその 2 倍。ミスの少ない選手・得意なコート・大事なポイントでは減る。
  決めにいく球は打ち損じなくても少し力む（ぶれ 1.3 倍）。これがないと AI は伸びきったときしかミスせず、ハイライトのようなプレーになる。
  100 ポイントあたりの凡ミス（同じ強さどうし）：EASY 約 18、NORMAL 約 17、PRO 約 12（現実のプロは 10〜15）
- 甘い球（質 5 割以上でベースラインより内側）は、22＋55×強気さ % の確率で決めにいく：高い打点ならフラットドライブに切り替えて 160＋25×強気さ km/h（トップスピンなら 145＋25×強気さ）
- AI のスライスは、40cm より低い球・遠い球・バックハンドの一部（片手バックの選手ほど多い）。
  膝くらい（40〜55cm）の球は、強気な AI ほど膝を曲げてトップスピンで持ち上げる。ライジングの名手は上がり際の低い球もそのまま振り抜く
  （前は 55cm 以下を全部スライスにしていて、球の低い芝ではフェデラーの半分近くがスライス、平均 87km/h になっていた）
- AI 同士の平均球速（サーブ以外、守りのスライスも含む）：EASY 約 98km/h、NORMAL 約 112km/h、PRO 約 117km/h。
  NORMAL の内訳：トップスピン 68%・122km/h、フラットドライブ 9%・137km/h、スライス 20%・67km/h

### 試合の記録で分かったことと、その対策

試合の記録（matchlog.csv）とプレイ記録（playlog.csv）を集計すると、人間の失点の約 7 割は自分のミスで、
その原因は「深い球で下げられ、走りながら遠い打点で打つ（打点の距離の中央値 1.33m、理想 0.94m）」ことだった。
スライスはまあまあの当たりでもネットが多く（40%）、AI の決め球は外れなかった（7 本中 7 本）。

- **足の自動調整（人間だけ）**：溜めている間、球がこの先 0.45 秒で一番近くを通る点を見て、その点を体の横 0.94m（理想の打点）で打てる位置へ、
  1.4m 以内なら小刻みに寄せる（最大 2.5m/s。自分の操作に上乗せ）。自分のタイミング（上がり際で打つなど）に合わせて動く。
  最初は「弾んだ後の打ちやすい高さ」の位置へ寄せていたが、上がり際で打つことが多いので効かなかった（打点の距離 1.36m → 1.35m）
- **タイミングの許容幅（人間だけ 1.5 倍）**：足の自動調整で打点の距離は良くなった（1.40m → 1.25m）が、タイミングのずれ（中央値 58〜92ms）が残った。
  AI のずれは NORMAL で ±12ms。マウスを離す瞬間で合わせるのは不利なので、人間だけタイミングがずれても質が落ちにくくする（AI が打つ間だけ 1 倍）
- **スライス**：開いた面で運ぶので、当たり損ねは下（ネット）より上（浮く）に外れる（下向きのぶれを半分に）。沈んでくる球で下へずれる分も半分。
  ネットの上の余裕は 30cm を目標にする。ベースラインの後ろからのスライスのネット：質 0.35 で 20% → 3%
- **AI の決め球**：打ち損じる割合を通常の 3 倍（最低 12%）、力み（ぶれ）を 3 倍に。打ち損じたときのぶれは、うまい選手でも普通の選手と同じ大きさにする。
  決め球が入る割合（ハード）：癖なし NORMAL 66%、フェデラー NORMAL 73%、ジョコビッチ PRO 87%

集計のしかた：

```sh
python tools/analyze_match.py matchlog.csv   # 失点の内訳、AI のウィナー、自分のミス、AI のサーブと打球
python tools/analyze_log.py playlog.csv      # 自分の打球：立ち位置とタイミングのどちらが悪いか
```

## よろめき（振られると立て直しに時間がかかる）

- 打った後の体勢の崩れ具合（0〜1）を、当たりの悪さ・打点の遠さ（伸びきり・踏み込み）・来た球の重さ・走りながら打った・下がりながら打った・打点の高すぎ低すぎから決める（ボレーは半分）
- 崩れた分だけ、立て直すまで（0.1〜1.5 秒）走る速さが落ちる（最初は 10%、だんだん戻る）
- AI は、相手が打った瞬間にまだよろめいていたら、残りの時間だけ一歩目（反応）が遅れる
- 自分（人間）は崩れ具合を半分にしている（球の方向を読む分、AI より不利なので）。反応の遅れもない
- 見た目：打った方へ体が流れて傾き、腰が落ち、左手を広げてバランスを取る。ポイントの間には戻る
- AI 同士の平均ラリー（サーブも 1 打）：ハード NORMAL 6.6 → 6.3 打、PRO 6.8 → 5.5 打、芝 PRO 4.9 打。ウィナーが増える

## 前で打つストローク（前に出た球はチャンス）

- ベースラインより内側で打つストロークは、速さはそのままで、ベースラインと同じ要領（同じ押す長さ）で入るようにしている。
  ネットから 11m より前で効き始め、6.5m（サービスラインのあたり）より前で最大
- 前ほどトップスピンを強くかける（最大 1.8 倍、フラットドライブは 2.6 倍）ので、同じ速さでもコートに落ちる。上下のぶれは最大 45% 減り、沈んでくる球で下へずれる分も 60% 減る
- ボレー・スマッシュ・ロブ・ドロップ・リターンには効かない
- 入る割合（同じ押す長さ、質 7 割）：サービスライン付近のトップスピンは 33〜76% → 96〜98%（ベースラインは 73〜97%）。
  フラットドライブも高さ 60cm 以上ならベースライン以上に入る。膝より低い球をサービスラインから 140km/h のフラットで打つのだけは、まだ長くなりやすい（トップスピンで）

## ロブとドロップ

- ロブもドロップも「タッチ」のショット：打ち出す角度は決まっていて（スライスロブ 50°、トップスピンロブ 40°、ドロップ 28°）、狙った深さに届く速さで運ぶ
- 深さは押す長さ：ロブはベースラインの 4.4m 手前（押さない）〜1.4m 手前（押しきり）、ドロップはネットの 1.8m 先〜4.5m 先
- 当たりが悪いほど深さがぶれる：ロブは 1〜2m、ドロップは距離の 3〜15%。来た球が速いほど難しい
- ドロップは、まあまあの当たり（質 4 割以上）なら、ネットにかけずに少し浮いて深くなる（甘くなるミスの方が多い）
- 入る割合（ベースラインから、質 5〜7 割）：ロブ 90〜100%、ドロップ 98〜100%
- 前はロブの速さに上限（最大 65km/h）があって空気抵抗で届かず、狙いより大幅に短くなっていた（スマッシュの的）。
  ドロップは距離のぶれが大きく（質 5 割で ±20%）、25〜57% がネットにかかっていた

## 球速について（なぜプロの 130km/h が出なかったか）

- **回転が足りなかった**：空気抵抗があると、回転（上から押さえる力）が少ない速い球はベースラインまでに落ちきらない。
  150km/h 以上でネットの 30〜50cm 上を越えてコートに収めるには 2500〜3000rpm 要る。
  前はフラットドライブが 1300〜1900rpm しかなく、速く打つとアウトするので AI は遅く打つしかなかった。今は 2300〜2900rpm
- **当たりの質が厳しすぎた**：質＝タイミング×距離×高さで、どれも 8 割の「悪くない当たり」でも 5 割になり、遅くなっていた。
  今は掛け算を 0.6 乗して緩めている（リターンは除く）。芯を外したときの遅くなり方も小さくした
- **空気抵抗は現実どおり**：120km/h の球はバウンド前に約 80km/h、弾んだ後 60km/h くらいになる。これは現実の測定とほぼ同じなので変えていない
- **逆回転の浮きすぎ**：キレのあるスライスは逆回転が強すぎて、速く打つと下に向けても落ちきらずアウトしていた。落ちきらない速さなら少し遅くして沈める（人間も同じ）
- コースは普段サイドラインの 1.1〜1.9m 内側、攻めるときは 0.9m 内側

## 長さのミス（上下のぶれ）

- 当たりが悪いほど、打ち出しの角度が上下にぶれる（ネット・アウトの原因）
- 速い球は角度が少しずれただけで遠くまで外れるので、速い球ほど角度のぶれを小さくしている（約 80km/h を基準に、速さに反比例）。
  外れる距離がそろい、長いアウトはほとんど 1〜2m 以内になる（当たり 50% で、アウトの真ん中の値 1.2m、最大 4m 弱）
- ぶれの上限も、速い球ほど小さい（80km/h で 4°）

## イン・アウトの判定

- 球が最初に弾んだ瞬間の位置で決める。球が少しでもラインに触れていればイン（規則どおり）
- ラインは規則どおりコートの内側に引いてある（コートの寸法はラインの外側まで）
- 弾んだ跡は、判定に使った弾んだ瞬間の位置に出す
- 弾んだ位置は、球が地面の高さを横切った瞬間を計算で求める。球は 1/240 秒ごとに動かしているので、ステップの終わりの位置を使うと、
  速い球は地面に触れた点より最大 10cm ほど先（コートの外側）になってしまう。前はそうなっていて、ライン際でインの球の約 3% がアウトになっていた
- アウトのときは「OUT 12cm」のように、球の端がラインからどれだけ外れたかを出す
- ボールは遠くでも見えるように、空中では実寸より大きく描く（遠いほど大きい）。地面に近づくと実寸（直径 6.7cm）に戻り、光のふちも消える。
  前は弾む瞬間も大きいままで（20m 先で実寸の 3 倍）、見た目ではラインに触れているのに判定はアウト、が起きていた
- 最初に弾んだ跡を、判定に使った実寸の大きさで 4 秒間残す
- 判定は電子判定（いつも正確）。だからチャレンジはない。代わりに、際どい球は拡大図で確かめられる
- 際どい球（球の端がラインの外側の縁から 8cm 以内）は、右上に上から見た拡大図を出す（ホークアイのように）。
  白い帯がライン（5cm）、黄色の丸が弾んだ跡。「OUT 1.2cm」「IN (on the line 0.8cm)」のように出る

## 狙いの印

打つたびに（サーブも）、狙いの印は真ん中に戻る。サーブはサービスボックスの真ん中から。
左右の狙い方はメニューの Aim で選ぶ。

- **CURVE（初期値）**：どこにでも狙える。少し振れば少し、大きく振るほどライン際に近づくが、ライン際（サイドラインの約 0.6m 内側）より外には出ない。
  コーナーへは思い切り振るだけでいい（マウスを狙いの単位で 1.6 振るとライン際までの約 76%）
- **LANES**：決まった位置から選ぶ。ラリーは 5 か所（左のライン際・左・真ん中・右・右のライン際）、サーブは 3 か所（ボックスの左端・真ん中・右端）。
  振りすぎても一番外で止まる。選べる位置が相手コートに小さな点で出る

## 伸びて取る（ランジ）：ぎりぎり届く球

ぎりぎり届く球は、現実のテニスと同じように、足を大きく踏み出し、腕とラケットを伸ばしきって取る（止まっていても、走っていても）。

- 届く限界は体の大きさで決まる。身長 185cm で、踏み出し＋体の傾き＋肩＋腕＋ラケット ≒ ストローク 2.6m（ふつうに届く 2.1m ＋ 0.5m）、ボレー 2.9m（＋ 0.8m）
- 背が高いほど遠くまで届く：伸びきったときの限界は身長 1cm あたり 1.4cm 変わる（ふつうに届く範囲の 4.5mm ＋ 伸びる分の 9.5mm）。
  198cm の選手は 2.78m、178cm の選手は 2.50m（ストローク）
- 伸びるほど当たりが悪くなる（面を合わせるだけ）：届く範囲を少し超えただけなら質の 7 割、伸びきってぎりぎりなら 3 割 5 分。
  打ったあと 0.6 秒は体勢が崩れて、走る速さが 35% になる（AI はその間動けない）
- 走っていても、伸びて届く球には飛びつかずに伸びて取る（前は、走っていると 2.1m の外はすべて飛びついて倒れていた）。
  飛びつき（倒れて 1.1 秒起き上がれない）は、伸びても届かない球だけ（ストロークで 2.6〜2.8m）
- 見た目：前の足を球の方へ大きく踏み出し、後ろの足は元の場所に残す（届かなくなるとつま先を引きずる）。腰を落として上体を倒し、
  打つ方の肩を球へ向け、肩から球まで腕とラケットをまっすぐ伸ばす（ラケットの面が球の所に来る）。両手バックの選手も片手で届かせる。
  取ったあと、0.6 秒かけて体を戻す。体の大きさで計算するので、背の高い選手ほど遠くまで届いて見える
- 足元の輪：内側が理想の距離、次がふつうに届く限界、いちばん外のごく薄い輪が伸びきって届く限界

## ボレー

- 速すぎて狙った所に落とせない（ネットを越えてから落ちきらない）ときは、面で勢いを殺して遅くする（最低 35km/h）。低いボレーは遅く浅く返る
- 面を固めて当てるだけなので、上下のぶれは普通のショットの 0.55 倍
- 沈んでくる球の「跳ね返りが下に行く」効果は、ボレーでは 0.3 倍
- 振らない：面を前に向けたまま、球へ 30cm ほど押し出して止める（パンチ）。ネット前（サービスラインの 1.5m 後ろより前）では、構えもラケットを体の前に出した小さな形になる。肩もあまり回さない
- **Q でしゃがむ**：押している間は腰を落とし、低い球を 0.3m 高い球として打てる（ローボレー、足元の球）。走る速さは 6 割になる

## AI のサーブのモーション

AI はボールを手に持って構え、トスを上げてラケットを担ぎ、トスの一番上を少し過ぎたところ（0.52 秒後）で打つ。
構えてからトスまでの間は毎回 1.2〜2.2 秒でばらつくので、数えて待つのではなく、トスを見て構える。

## 高い打点から叩く

浮いた遅い球を肩の高さで打てれば、ベースラインからでも上から叩ける。

- 理想の高さより上に「質が落ちない幅」がある：フラット 0.5m（1.2〜1.7m まで）、トップスピン 0.25m、スライス 0.3m。
  トップスピンは肩より上だと振り上げにくいので狭い
- ただしこの幅が効くのは遅い球だけ（来た球 50km/h 以下で全部、90km/h 以上でなし）。
  速くて重い高い球（キックサーブ、深いトップスピン）は肩の上だと押されるので、高い球で攻める戦術は残る
- 打点が高いと上から下に打てるので、物理的にもネットとアウトの余裕が大きい
- 2m 前後の頭上の球も、少し低めならスマッシュで叩ける（理想 2.55m より下は許容を広く）
- **チャンスボール**：自分より高い遅い球（1.1m から上、1.7m で最大）は、当たりが多少悪くても威力が出てぶれにくい
  （当たりの悪さを最大 6 割取り戻す。質 30% でも 72% 相当）。上から下に打つので角度もつき、アウトしにくい
- 遅い球は膝を曲げて合わせる時間があるので、高さの許容幅も広い（50km/h 以下で 1.6 倍）
- チャンスボールは前後（タイミング）と左右（体からの距離）の許容幅も広い（最大 1.8 倍）
- どれもサーブのリターンには効かない（反応で打つ球なので余裕なし扱い）
- リターン：プロのように跳んで伸びて取る。届く範囲が 0.45m 広い（届くだけで、伸びた分の半分は当たりが悪くなる）。
  自分のスイングはコンパクト（6.5 割）なので遅く高い弾道になり、入るが浮きやすい
- AI のサーブは、強いほどライン際の深いところへ打つ（返されないのは速さよりコース）。ラインからの距離：EASY 0.6m、NORMAL 0.42m、PRO 0.3m。
  コーナー（T かワイド）に打つ割合は EASY 6 割、NORMAL 7 割、PRO 8 割。セカンドは 0.3m 内側で浅め
- 跳ね返りの分は、来た球の上下の動きを持ったまま出ていく。跳ね上がってくる速い球（サーブ）を返すと上に行きやすく、沈んでくる球は下（ネット）へ行きやすい。うまく当てるほど抑えられるが、半分は残る

## ライジング（上がり際で打つ）

特別なルールは足していない。物理と打点の判定から自然に出る：

- **得**：早く打つほど相手に時間がない（弾道を計算しているのでそのまま効く）。バウンド直後は球が速いので、跳ね返りの分で球速も出る
- **難しさ**：上がり際は球が上下に速く動くので、タイミングが少しずれると打点の高さが大きくずれる（高さの質が落ちる）。頂点付近は高さが変わらないので楽
- 当たった後の表示に「on the rise / at the top / dropping」が出る。記録の `ball_vy` 列（プラス＝上がり際）で、どこで打つと入りやすいか集計できる

## 手がかり表示（H）

画面には奥行きがないので、まっすぐ向かってくるボールの「いつ」「どこ」が目で読めない。それを画面で補う（物理や判定は変えない）。

- **タイミングの輪**：理想の打点のまわりの輪が、一番いい瞬間に向かって縮む。網の球と重なったら離す。
  輪の色は「今の位置のまま一番いいタイミングで振ったら何%か」：緑＝位置 OK、黄＝まあまあ、赤＝足を動かす
- **弾む点（オレンジの輪と×）**：相手が打った瞬間に、自分のコートのどこで弾むかを出す（弾むまで）
- **通り道（地面の線）**：弾んだ後の球の通り道。溜めている球種で打ちやすい高さの区間だけ緑で太く、それ以外は灰色
- **立つ場所（緑の輪と矢印）**：打ちやすい高さで打てる位置。自分の足元から矢印が出る。着いたら輪の中が緑に塗られる。
  黄色の球は、そこで打つときのボール
  - 相手が打った瞬間に一度だけ決める（溜める球種を変えたときだけ作り直す）。毎フレーム作り直さないので、目印が跳ねたり消えたりしない
  - 出遅れても消えない。間に合わない場所は避けるが、どこも間に合わなければ一番ましな場所を出す
- H で切替：タイミング＋立つ場所 → なし → タイミングだけ。記録の `assist` 列に残るので、効果を比べられる

## プレイ記録（なぜ難しいかを調べる）

遊ぶと、実行したフォルダの `playlog.csv` に 1 球ごとの記録が追記される。Tab でこのセッションの統計を表示。

| event | 中身 |
|---|---|
| swing | 振った球：球種、溜め、フォア/バック/頭上、空振りの理由、質（タイミング・距離・高さ）、打点（向き・距離・高さ）、来た球と打った球の速さ、結果（IN/OUT/NET/WHIFF） |
| no_swing | 振らなかった球：一番近づいた距離と向き、届く距離を通ったか、入る球だったか |
| serve | サーブ：球種、溜め、打点の高さ、球速、結果 |

一番大事な列：

- `best_quality_here`：その立ち位置のまま、一番いいタイミングで振っていたら質は何%だったか
- `timing_offset_ms`：その一番いい瞬間から何 ms ずれていたか（マイナス＝早い、プラス＝遅い）

`best_quality_here` が低ければ足（立ち位置）の問題、高いのに当たりが悪ければ手（タイミング）の問題。

各行の最後に日付と時刻（`datetime`）が入るので、集計の最初に「日ごとの遊んだ時間」が出る（打球と打球の間が 2 分以内のところだけ数える）。
列が増えたので、前の記録は `playlog_old_<番号>.csv` という名前で残り、新しい `playlog.csv` が始まる。

```sh
python tools/analyze_log.py playlog.csv
```

で、結末・原因の切り分け・タイミングのずれの分布・打点・来た球の速さ別の成功率・振らなかった球・反応時間・サーブをまとめて出す。

## 打点と届く範囲

距離はすべて「体の中心から、ラケットの芯で触れるボールの中心まで」（ラケットを持っている前提）。
理想 0.94m は肘を少し曲げた楽な姿勢。届く限界 2.1m は 肩 0.2m＋腕 約 0.7m＋手から芯 約 0.55m（≒1.5〜1.6m）に最後の踏み込み 0.5m を足したもの。

打点は「体の真横の 1 点」ではなく、体のまわりの立体的な範囲で考える。
上から見て、体からボールまでの距離と向き（真横 0°、真正面 90°）、それと高さで評価する。

| 打ち方 | いつ | 理想 |
|---|---|---|
| フォア / バック | ボールが 1.85m より低い | 体から 94cm、向き 25°（横やや前）。ボレーは 40°（もっと前） |
| 頭上（スマッシュ・ハイボレー） | 1.85m より高い（ジャンプで 3.05m まで） | 高さ 2.55m、体の少し前右。J/L はスマッシュ、K はスライスで合わせる |
| 伸びて取る | 届く限界（2.1m）の外、2.6m まで（ボレーは 2.9m。身長で変わる） | 足を踏み出し、腕とラケットを伸ばしきって取る。質は 70%〜35%（伸びるほど落ちる）、0.6 秒体勢が崩れる |
| 飛びつき | 伸びても届かない球、2.8m まで | ボールの方向に 2.5m/s 以上で走っていれば自動で飛びつく。質は 35% になり、1.1 秒倒れて動けない |

- 前にあるボールも、向きがずれるだけで（早い＝引っ張り気味）、届けば打てる
- 後ろ（-55° より後ろ）に入られたら振り遅れ

### ボールの見え方

- 実寸（直径 6.7cm）だと遠くで数ピクセルになるので、遠いほど少し大きく描き、光るふちをつける（当たり判定は実寸のまま）
- ボールから地面への縦の線と影で、高さと位置が分かる
- 軌跡は新しいところほど濃い。相手の球は明るい色
- バウンドした場所に輪が一瞬出る

### 見えるもの

- 体とラケット。溜めている間はテイクバック、離すとスイング（白い軌跡）とフォロースルー
- 地面の輪：内側が理想の距離、外側（薄い）が届く限界
- 振った後 2.5 秒間：白い網の球＝理想の打点、色つきの球＝実際のボール、その間の線＝ずれ。空振りでも出る
- 左上：タイミング（向きのずれ °）、距離、高さ。空振りなら、ボールがどこにあったか

## 試合（AI 対戦）— 起動するとこのモード

メニューの Match length で 1 セット / 3 セットマッチ（初期値）/ 5 セットマッチ。各セットは 6 ゲーム先取、6-6 でタイブレーク。15/30/40、デュース、アドバンテージ、ファースト/セカンド、フォルト、ダブルフォルト。

| キー | 動作 |
|---|---|
| 1 / 2 / 3 | AI の強さ：EASY / NORMAL / PRO（試合をやり直す。試合の途中は効かない） |
| B | オートパイロット：自分側も AI が操作する（観戦用） |
| Enter | 試合終了後、新しい試合 |
| G | モード切替：試合 → ラリー練習 → リターン練習 → サーブ練習（試合の途中は効かない。試合が終わった後なら切り替わる） |

### AI のしくみ

AI は自分とまったく同じ物理・打点の評価・ショットの関数を使う（コートを 180° 回した座標で、プレイヤー用の関数を呼んでいる）。ズルはしない。

- 相手が打ってから反応時間だけ待って、球の軌道を予測する
- 1 バウンド目がアウトなら見送る（際どい球は見極めを間違えることがある）
- 間に合って、打ちやすい高さ（1m 前後）になる点を選んで走る。理想の距離が無理なら、踏み込んで届く位置を目指す
- 球種：低い・遠い球はスライスでつなぐ、高くていい打点はフラットで叩く、相手が前に来たらロブ
- 甘い球（いい打点・ベースラインの内側）は決めにいく
- コースは相手のいない方へ。強い AI ほど厳しく

| AI | 走る速さ | 反応 | タイミングのばらつき | 立ち位置のずれ | 強気 | ファースト | セカンド | サーブの安定感 |
|---|---|---|---|---|---|---|---|---|
| EASY | 5.0 m/s | 0.35 秒 | ±22 ms | 35 cm | 0.25 | 155 km/h | 105 km/h | 0.56 |
| NORMAL | 5.6 m/s | 0.28 秒 | ±12 ms | 20 cm | 0.50 | 175 km/h | 120 km/h | 0.70 |
| PRO | 6.2 m/s | 0.22 秒 | ±7 ms | 10 cm | 0.75 | 195 km/h | 130 km/h | 0.80 |

AI のサーブ（試算）：ファーストは 58〜60% 入る、セカンドは 85〜92% 入る（現実のプロは 60〜65% と約 90%）。

スコアはサーバーの点を先に言う（サーバーが 15、レシーバーが 0 なら 15 - 0）。
右上のスコア表：サーブ中の印（● と 2nd）、ゲーム数、ポイント（0/15/30/40/AD、タイブレークは数）。
その下にゲームの流れ（白＝自分、青＝AI が取ったゲーム。B はブレーク）。
Tab の統計に、試合中のサーブの成績（ファースト・セカンドの入った割合、返されなかったサーブ、ダブルフォルト）を自分と AI の両方出す。

## ステップ3：打点システム（いまここ）

球出しマシンが相手コートからランダムに球を出す。動いて、溜めて、タイミングよく離して打ち返す。

打点は3つの要素で評価し、掛け算したものが「質」（0〜100%）になる。

| 要素 | 理想 | ずれると |
|---|---|---|
| タイミング | 体より 40cm 前 | 早い→引っ張る（フォアなら左）、遅い→流れる |
| 体からの距離 | 85cm | 近い＝詰まる、遠い＝伸びきる |
| 高さ | 球種ごとに違う（フラット 1.2m / トップ 1.0m / スライス 0.75m） | その球種が打ちにくい高さ |

質が悪いと、球速と回転が落ち、狙いが左右・上下に散らばる。

### 来た球の勢い

返球の速さ ＝ 0.4 × 来た球の速さ ＋ 1.4 × ラケットの速さ（実際のラケットの反発に近い式）。

- 溜めなしで離すとコンパクトなスイング（ブロック）。タイミングの許容幅が広く、来た球の勢いで返す
- 大きく溜めるほどタイミングがシビア
- ノーバウンドで打つとボレー。自分の力は 4 割しか乗らないが、タイミングの許容幅は広い
- ラケット面のずれは、跳ね返る成分では 2 倍効く。速い球ほど狙いが狂い、深さもばらつく
- 芯を外したときのラケットのねじれ：45km/h を超える重い球ほど、打点のずれが大きく響く（速いファーストサーブが決まる理由）
- キー入力は 1/60 秒単位でしか取れないので、離したフレームの間で一番いい瞬間を採用する
- 前に踏み込みながら打つと（W を押しながら）、球が重くなり（最大 +12km/h）、ぶれが減る（最大 35%）。下がりながらだとぶれが増える

### 速さの違い

| 球 | 打ち出し | 自分が打つ瞬間 | 届くまで |
|---|---|---|---|
| プロのラリー | 120 km/h | 約 53 km/h | 約 1.0 秒 |
| ファーストサーブ | 200 km/h | 約 93 km/h | 約 0.6 秒 |

同じ打点のずれでも、速い球ほど狙いが大きく狂う。だからサーブは決まり、まっすぐ当てて踏み込めば返る。

## サーブ（G でモード切替）

- A/D で立ち位置（センターマークの片側だけ）
- L=フラット / K=スライス / J=キック を押すとトス、溜めて、離した瞬間に打つ
- トスの最高点は 2.95m。2.9m 以上で打てば満点（腕を伸ばしきった一番高いところ）。落としすぎると打点が低くなって減点され、物理的にも入りにくい
- 溜めはトスを上げた瞬間から溜まり、0.45 秒（トスの一番上）で最大。一番上あたりで離せばフラットで 215km/h 出る
- トスは毎回少しぶれる。悪いトスは押しっぱなしで見送れる（1.2m まで落ちるとやり直し、ペナルティなし）
- 離した瞬間の A/D でコース（ボックスの左右の端）、なしでボディ。W/S で深さ
- 溜めるほど速いが、ぶれも大きい
- 回転：スライスは横回転で曲がる。キックはトップスピン＋進行方向まわりの回転で、高く跳ねて横に跳ねる

| サーブ | 速さ | 特徴 |
|---|---|---|
| フラット | 150〜215 km/h | 一番速いが、ネットの余裕 15〜20cm |
| スライス | 140〜190 km/h | 空中で外へ曲がる。ワイドが効く |
| キック | 120〜170 km/h | ネットの余裕 45〜50cm。高く跳ねて横に跳ねる。セカンド向き |
画面の HUD に、どの要素が悪かったかを毎回表示する。

## ブラウザ版・体験版（make web）

ブラウザで遊べる体験版を作る（売る版の名前、1 セットの試合、グランドスラムなし、スローと自動操作なし）。

1. emsdk を入れる：`git clone https://github.com/emscripten-core/emsdk` → `./emsdk install latest` → `./emsdk activate latest` → `source ./emsdk_env.sh`（Windows は `emsdk_env.bat`）
2. raylib をブラウザ向けに作る：raylib の `src/` で `make PLATFORM=PLATFORM_WEB`（libraylib.a ができる）
3. `sweetspot/` で `make web WEB_RAYLIB=<raylib の src>` → `web/out/` に index.html・.js・.wasm・.data
4. 試すときは `web/out/` で `python3 -m http.server` → ブラウザで http://localhost:8000（ファイルを直接開いても動かない）

ブラウザでは Esc はマウスの固定を外すのに使われる。固定が外れたら Esc と同じに一時停止のメニューを出す。
画面の大きさはページに合わせる。設定は保存されない（ページを開き直すとはじめから）。

- 設定はブラウザの保存場所（localStorage）にも写すので、ページを閉じても残る（storage.c の `StoreRestore`・`StorePersist`。キーは `sweetspot_` ＋ファイル名）

### チャレンジ：AI「ふつう」以上に「リアル」で勝つと、製品版が無料

勝つと結果の画面に「勝利の証明コード」（`SS-XXXXX-XXXXX-XXXXX-XXXXXX`）が出る（C でコピー）。
コードには相手・AI の強さ・難しさ・ゲーム数・取ったポイント・日付と、秘密の鍵から作った確かめの数字が入っている（demo.c）。
試合の途中で強さを「やさしい」にしたり難しさを「カジュアル」にしたりすると、コードは出ない。
確かめるのは `python3 tools/check_code.py <コード>`（同じ鍵 `web/demo_secret.txt` を使う。鍵はリポジトリに入れない）。
鍵は体験版の中に入っているので、本気で調べれば取り出せる。小さなチャレンジとしては十分だが、配る数が増えたら鍵を変えて作り直す。

## テニスの外の楽しみ（試合のポイントの間）

- **E：観客をあおる**。押すたびに「カモン！」・拳・跳んで拳・両手を上げる・吠える（ふつうの版は耳に手を当てるも）を順に。
  ポイントを取った後なら観客が沸いて少し「燃える」。同じゲームで 3 回目から、または取られた後だとブーイング
- **Z：球を観客席へかっ飛ばす**。奥の観客席まで飛んで、観客が捕って沸く。行為違反（ラケット破壊と同じ数え方：警告 2 回、3 回目からポイントペナルティ）。燃えるがラケット破壊より弱い
- **ハプニング**（ポイントの間にたまに）：
  - ハトがコートに降りてきて歩き回る。ボールキッズが走って追い払うと飛んでいき、観客が笑って拍手（約 5%）
  - 観客が騒がしくなり、主審が「お静かに願います」→「ありがとうございます」で静かになる（約 5%）
- **Y：カモン！**（拳を握って喜ぶ。ポイントの間なら何回でも。ポイントを取った直後なら観客が少し沸く。**相手のサーブのトス中・相手の打球中に押すとヒンドランス（妨害）で相手のポイント**）
- E・Z・Y もキー設定で変えられる

## バトルモード（タイトルの「プレイ」で ←→、または 選手と試合 → モード）

ふつうの試合に体力ゲージがつく。1 セットの試合で、体力が 0 になったらその場で K.O. 負け。

- 相手に決められると体力が減る：ウィナー 14、エース 16（燃えていると、与えるダメージが最大 1.5 倍）。自分のミス（ネット・アウト・ダブルフォールト）ではポイントを失うだけで、体力は減らない
- 長いラリー（7 本目から）は両方が少しずつ疲れて減る
- **ボディショット**：打った球が、相手の体（腰から頭）にバウンド前か 1 バウンドで当たると、打った方のポイント。24 減り、当たった方は倒れる（ふつうの試合でもボディショットは得点。バトルは当たる範囲が広い）
- AI もときどき（2 割）体を狙ってくる（強いフラットで、足もとの 3m 手前に落とす）
- 画面の上に 2 人の体力ゲージ。0 になると「K.O.」
- 数字は game.h の BATTLE_ で始まる値（体力、ダメージ、当たる範囲、AI が体を狙う割合）
- 体験版でもバトルは遊べるが、「NORMAL に勝ったら無料」のチャレンジはふつうの試合だけ

## はじめての人へ（タイトルの 2 番目）

4 つの短い練習で操作を覚える。画面の右上に、やることと進み具合が出る。

1. 動く：光る円の中へ（その間は球が来ない）
2. 打つ：来た球を 3 球入れる（押して、離して振る）
3. 狙う：マウス（または U / O）で狙いを動かし、左と右に 1 球ずつ入れる
4. サーブ：2 本入れる

終わるとタイトルに戻り、モードは「試合」になる。始めると「手がかり」は「タイミング＋立つ場所」になる。Esc → タイトルに戻る でやめられる。

- 練習を最後（サーブ 2 本）まで終えると、4 秒後に「ひとつ提案」：そのまま初めての試合（相手：やさしい・難しさ：カジュアル・タイブレーク）を始めるか、タイトルへ戻るか
- 初めて起動した（設定ファイルがない）ときは、タイトルで「はじめての人へ」を選んだ状態で開き、「はじめての方は、まず 1 分の練習から（Enter）」と出す。何かを始めると設定が保存され、次からはふつうのタイトル

## 撮影モード（試合・練習の中で F3）

宣伝用の画像・動画を撮るための画面。画面の文字・狙いの印・手がかりの円を消し、カメラを映画のような位置に置く。
F3 を押すたびに「中継（低め）→ 真横 → すぐ後ろ → まわりを回る → 元に戻る」。F12 で画面を保存。動画は Windows の Xbox Game Bar（Win＋G）で。

## 試合の長さ・ラリー練習・ドット風の細かさ（追加）

- 試合の長さ：タイブレーク（7 点先取、2 点差）→ ショートセット → 1 セット → 3 セットマッチ → 5 セットマッチ。タイブレークだけの試合は最初からタイブレークで、結果はタイブレークの点（例 7-5）
- ショートセット：4 ゲーム先取（2 ゲーム差）、4-4 でタイブレーク（結果は 5-4）。10〜15 分で「ゲームの流れ」を味わえる長さ。保存の値は `sets=4`（0〜3 の意味は前のまま）
- グランドスラムのほかの試合も、選んだ長さで計算する（タイブレークだけの大会なら、ほかの試合もタイブレークの点で出る。前は 6-4 のように出ていた）
- ラリー練習：相手が球を出した後、自分が打ち返すと相手も走って打ち返す（決めにいかず、打ちやすい所へつなぐ）。2 バウンド・アウト・ネットでラリーが終わり、次の球を出す
- ドット風は縦 360 ドット（240 では粗すぎた）

## 滑り込み（設定の「滑り込み」）

はじめは「なし」：溜めながら速く走っていても、止まるときはいつもどおりピタッと止まる（「走るとしっかり止まれない」と不評だったため）。
「あり」にすると、溜めながら速く走っていて止まる・切り返すときに滑り込む（リーチが少し伸びる）。滑る距離は以前の約 6 割で、反対向きに入れるとすぐ止まる。
AI の滑り込みは今までどおり。
