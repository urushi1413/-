SWEET SPOT — 打点と回転がものをいう本物のテニス

■ 起動
  SweetSpot.exe をダブルクリック。sounds と fonts のフォルダは exe と同じ場所に置いたままにしてください。
  設定は同じフォルダの sweetspot_settings.txt に保存されます。

■ 遊び方（試合中）
  WASD ............ 移動
  マウス .......... 狙う場所（左右・深さ）
  左クリック ...... トップスピン（長く押すほど深く。離して打つ）
  右クリック ...... スライス
  Space＋クリック .. フラット
  Shift＋クリック .. ロブ
  Ctrl＋クリック ... ドロップショット
  Q ............... しゃがむ（低い球）
  X ............... ラケットを叩きつける（ポイントの間）。数ポイント「燃える」：速く強くなるが、ミスも増える。
                    3 回目からポイントペナルティ
  E ............... 観客をあおる（ポイントを取った後なら観客が沸く）
  Y ............... カモン！（拳を握って喜ぶ。相手のサーブ中・打球中に押すとヒンドランスで相手のポイント）
  Z ............... 球を観客席へかっ飛ばす（行為違反。ラケットを叩きつけるのと同じ数え方）
  R ............... ポイントの後：リプレイ（C でカメラを切り替え）
  Tab ............. 成績
  F3 .............. 撮影モード（画面の文字を消して、カメラを変える。押すたびに次へ）
  F1 / F2 ......... 画面の表示 / ガイドの切り替え
  M ............... 音を消す / 戻す
  Esc ............. メニュー

■ キーボードだけで遊ぶ（マウスなし）
  J / K / L ....... トップスピン / スライス / フラット（サーブはキック / スライス / フラット）。Shift を押しながらでロブ、Ctrl でドロップ
  U / O / I / 、 .. 狙い：左 / 右 / 深く / 浅く

■ キーを変える
  設定 → キー設定。操作を選んで Enter（またはクリック）を押し、新しいキーを押す。
  ほかの操作がそのキーを使っていたら、2 つを入れ替える。「はじめの割り当てに戻す」で元どおり。

■ はじめての人へ
  タイトルの「はじめての人へ」で、動く → 打つ → 狙う → サーブ を順に練習できます。

■ サーブ
  左クリック キック / 右クリック スライス / Space＋クリック フラット
  押してトスを上げ、離して打つ。トスのいちばん高いところあたりで離すといいサーブになる。
  悪いトスは押したまま見送ると、トスをやり直せる。

■ モード
  試合 / ラリー練習 / リターン練習 / サーブ練習
  グランドスラム：16 人の勝ち抜き。4 大会を続けて回るシーズンもあります。
  AI の強さ（やさしい・ふつう・プロ）と、難しさ（カジュアル・リアル）を選べます。
  はじめての人は「カジュアル」と AI「やさしい」がおすすめです。

■ 動作環境
  Windows 10 / 11（64 ビット）、OpenGL 3.3 に対応したグラフィック、マウス
