# 選手の体のモデル（試作）

- `player.blend`：Blender で直す元。
- `player.glb`：ゲームが読むファイル。

ゲームでは「設定 → 選手の体 → Blender のモデル（試作）」にすると、選手の体がこのモデルになります。

## 仕組み
- 動き（打つ・走る・構える）は、今までどおりゲームのコードが関節の位置を計算します。
- ゲームは、その関節の位置にモデルの骨を合わせて体を曲げます。
- だから、モデルの形や太さを変えても動き方は変わりません。
- 骨の長さを変えた場合は、ゲームの関節の位置に合わせて伸び縮みします。
- 頭・顔・髪・ラケット・リストバンドは、今はゲームのコードが描いています。このモデルは首から下です。

## 直すときに守ること
1. **骨の名前を変えない。** ゲームは名前で骨を探します。
   - 使う骨：`hips` `spine` `chest` `neck` `head`、`upperarm` `forearm` `hand` `thigh` `shin` `foot` の `.R` と `.L`。
   - 骨のしっぽの位置を知るための骨：`head_end` `hand_end.R/.L` `foot_end.R/.L`。消さないでください。
   - 骨を足すことはできます。足した骨は、親の骨と一緒に動きます。
2. **マテリアルの名前で色が決まる。** ゲームが選手ごとの色を付けます。
   - 使う名前：`skin`（肌）、`shirt`（シャツ）、`shorts`（ショーツ）、`socks`（ソックス）、`shoes`（シューズ）、`sole`（靴底）、`hair`（髪）。
   - ほかの名前のマテリアルは、Blender で付けた色のまま出ます。ロゴやラインなどに使えます。
   - テクスチャ（画像）は今は使いません。色だけです。
3. **大きさ：** 1 = 1 m。身長 1.85 m の選手の大きさで作ります。ゲームが選手ごとの身長に合わせて大きさを変えます。
4. **向き：**
   - 正面は -Y です。Blender の Front ビュー（テンキーの 1）で、選手がこちらを向きます。
   - 選手の右側（`.R` の骨）は +X 側です。
   - 骨の姿勢は、今の立った姿勢（腕を下ろした形）のままにしてください。ゲームはこの姿勢を基準に曲げます。
5. **骨の重み：** 1 つの頂点に効く骨は 4 本までです。それ以上あると、書き出すときに強い 4 本だけが残ります。
6. **重さ：** 三角は数千くらいまでにしてください。今は 1660 です。2 人分を毎フレーム、コンピューターの中で曲げて描いています。

## 書き出し（File → Export → glTF 2.0）
次のように設定して、`models/player.glb` に上書きします。

- Format：**glTF Binary (.glb)**
- Include：Selected Objects は**外す**
- Transform：**+Y Up をオン**（初めのまま）
- Data → Mesh：**Apply Modifiers をオン**
- Data → Armature：**Export Deformation Bones Only は外す**（`_end` の骨も要るため）
- Animation：**外す**（動きはゲームが付けます）

書き出したら、ゲームを起動し直すと読み込まれます。作り直さなくても大丈夫です。

## 初めの形をもう一度作る
次のコマンドで作り直せます。手で直した `player.blend` と `player.glb` は上書きされます。

```
blender --background --python tools/make_player_model.py
```
