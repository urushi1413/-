# 選手のパーツモデル

| ファイル | 中身 |
|---|---|
| `player.glb` | ゲームが読むモデル |
| `player.blend` | Blender で直す元 |
| `palette.png` | 16x16 の色の表（パレット） |
| `palettes/<選手の短い名前>.png` | 選手ごとの色の表（なくてもよい） |
| `faces/face_01.png`〜`face_04.png` | 顔の絵（128x128。白目・黒目・眉・口。背景は透明） |
| `players.txt` | 選手ごとの髪型と顔の絵 |

作るスクリプトは `tools/make_player.py` です。sweetspot フォルダで、次のどちらかで動かします。

```
blender --background --python tools/make_player.py
python3 tools/make_player.py      （pip で bpy を入れた Python のとき）
```

調整用の数値は、スクリプトの最初にまとめてあります。頭の倍率、手足の太さ（先細りの各所の半径）、袖の太さと長さ、パンツの裾の長さと広がり、靴の大きさ、角の数、顔の絵の目や眉の形などです。

ゲームでは「設定 → 選手の体 → パーツモデル（Blender）」を選ぶと、このモデルになります。その下の「モデルの輪郭線」で輪郭線を付けたり消したりできます。初めは「なし」で、付けると細い線（アニメ調の半分の太さ）になります。

## しくみ
- 体は部位ごとの別のオブジェクトです。スキニングはしません。
- ゲームは、コードが計算した関節の位置と向きに、パーツをそのまま置きます。

| オブジェクト | 原点（親の関節） | +Y の向き（子の関節） |
|---|---|---|
| `pelvis`（腰・パンツ） | 腰の中心 | ウエスト |
| `torso`（胴・シャツ） | ウエスト | 首の付け根 |
| `neck` | 首の付け根 | 頭の付け根 |
| `head`（頭の形・鼻。髪の生え際から上は髪の色） | 頭の付け根 | 頭の上（顔の上の向き） |
| `face`（顔の絵を貼る薄い面） | 頭の付け根 | 頭の上 |
| `hair_short` `hair_wave` `hair_tied` `hair_buzz`（髪型の候補） | 頭の付け根 | 頭の上 |
| `upperarm.R/.L` | 肩 | 肘 |
| `forearm.R/.L` | 肘 | 手首 |
| `hand.R/.L` | 手首 | 手の先 |
| `thigh.R/.L` | 股関節 | 膝 |
| `shin.R/.L` | 膝 | 足首 |
| `shoe.R/.L` | 足首 | つま先 |

- **各パーツの座標：**
  - 原点は親の関節です。
  - +Y は子の関節の方を向きます。
  - +X は選手の右です（.R が右）。
  - +Z は X×Y です。上向きのパーツでは前、下向きのパーツでは後ろになります。
- **大きさ：** 1 = 1 m です。身長 185 cm の選手の大きさで作ります。選手ごとの身長と体つきは、ゲームが合わせます。
- **長さの合わせ方：** 頭・手・靴は形を保ちます。それ以外は、関節の間の長さに合わせて縦に少し伸び縮みします。基準の長さは、オブジェクトの `len` プロパティです。

## 色
色は `palette.png` のマスです。各面の UV が、マスの真ん中を指しています。

| マス（列, 行） | 色 |
|---|---|
| (0, 0) | 肌 |
| (1, 0) | シャツ |
| (2, 0) | シャツの差し色（襟・裾・胸のライン・袖口） |
| (3, 0) | パンツ |
| (4, 0) | 靴 |
| (5, 0) | 靴下 |
| (6, 0) | 髪 |
| (7, 0) | リストバンド |
| (8, 0) | 目 |
| (9, 0) | 靴底 |

- **ゲームが入れ替える色：** 選手ごとに、上のマスの色を、その選手の肌・シャツ・パンツ・髪などの色に入れ替えます。
- **ほかのマス：** 行 1 から下などは、`palette.png` の色のままで出ます。ロゴやラインなどに使えます。
- **選手ごとの色の表：** `palettes/<選手の短い名前>.png` を置くと、その選手は全部そのファイルの色で描きます（例：`palettes/NADAR.png`）。名前は選手を選ぶ画面に出る短い名前です。売る版では、架空の名前になります。

## 顔と髪
- **頭の形：** 球を変形しています。あごは細く少し前へ出し、頬はわずかに削り、後頭部は少し出しました。鼻は小さな三角柱です。
- **顔の絵：** 目・眉・口は形ではなく、`face` に貼る絵（`faces/face_XX.png`）です。`face` の UV は正面から投影しています。
- **髪：** 細長いくさび形の毛束を、前髪・トップ・サイド・襟足に、向きを変えて約 15 本並べています。頭の皮膚の生え際から上は髪の色です。
- **髪型の候補：**
  - `hair_short`：短髪
  - `hair_wave`：ウェーブ
  - `hair_tied`：長めを後ろで束ねる（ゴムはリストバンドの色）
  - `hair_buzz`：坊主寄り
- **選手ごとの選び方：** `players.txt` で、選手の番号ごとに `hair=` と `face=` を指定します。書いていない選手は、ゲームの髪型と男女から選びます。
- **髪の色：** 選手の髪の色（コードの値）です。`palettes/` の表を使えば変えられます。

## 手で直すときに守ること
1. オブジェクトの名前を変えない。ゲームは名前でパーツを探します。
2. オブジェクトの原点・向きを動かさない。
   - 形だけを直してください（Edit モードで頂点を動かす）。
   - 原点を動かすと、関節からずれます。
3. オブジェクトを親子にしない。
4. 色は UV をパレットのマスに置いて決める。テクスチャの絵は描かない。
5. 書き出しは File → Export → glTF 2.0 で、次のように設定して、`models/player.glb` に上書きします。
   - Format：glTF Binary（.glb）
   - Transform：+Y Up をオン
   - Data → Mesh：Apply Modifiers をオン
   - Include → Custom Properties をオン（`len` のため）
