# スキニングの選手モデル（models/players/）

ゲームの「設定 → 選手の体 → スキニング（Blender）」で使うモデルです。

| ファイル | 中身 |
|---|---|
| `p00.glb`〜`p16.glb` | 選手の番号ごとのモデル。`p00` は癖なしの選手で、ほかの選手の glb がないときにも使う |
| `bones.txt` | 骨の対応表（元のモデルの骨の名前 → ゲームが見る名前） |
| `SOURCE.txt` | 元のモデルの出どころとライセンス |
| `faces/face_01.png`〜`face_04.png`・`beard_1.png`・`beard_2.png` | このモデル用の顔の絵・剃り跡・ひげ（256x256。下の「頭・顔・首の比率」の配置。スクリプトが作る） |

## 作り方
1. 商用利用できるリグ付きの人体モデル（glb）を `sweetspot/assets/base_body.glb` に置きます。
2. ライセンスを確かめます（下の「ライセンスの確かめ方」）。
3. sweetspot フォルダで次を実行します。全員分で数十秒かかります。
   ```
   blender --background --python tools/make_skinned_players.py
   ```
   `ONLY=0,2` を付けると、その番号の選手だけを作ります。別の場所のモデルを使うときは、`BASE_BODY=パス` を付けます。
4. スクリプトがすること：
   - 骨の名前を決まった名前に付け替えます。指などの細かい骨は手・足に合わせて消します。
   - 服を色分けします。袖口・リストバンド・腰・パンツの裾・靴下・襟の所では、メッシュに切れ目を入れて、まっすぐな境目にします。
   - 髪・鼻・顔の絵を貼る面を、頭の形に沿わせて作ります。
   - 選手ごとの体型（`data.c` の BODY と `HEAD_SCALE`）を入れて、`p00.glb`〜`p16.glb` を書き出します。

## 頭・顔・首の比率
頭の形・顔の部品・首・肩線は、スクリプトの最初の「頭・顔・首・肩の比率」の数値で決めます。基準は 2 つです。

- **縦：** 頭の高さ h（頭頂（髪を含む）〜あご先）＝ 1 とした、頭頂からの位置です。
- **横：** 目の幅 E（＝ 頬骨の幅 / 5）の単位です。

| 項目 | 値 |
|---|---|
| 生え際 / 眉（＝耳の上端）/ 目 / 鼻の下（＝耳の下端） | 0.28 / 0.495 / 0.535 / 0.7475 |
| 口 | 鼻の下→あご先の、上から 1/3 |
| 目の幅・両目の間・鼻の幅 | E |
| 口の幅 | 1.5E |
| 頬骨の幅 | 5E |
| こめかみ / あご / 頭の最大幅（頬骨の幅に対して） | 0.90 / 0.725 / 1.075 |
| 頭の幅 / 頭の高さ | 0.775 |
| 奥行き（鼻先→後頭部）/ 頭の高さ | 0.975 |
| 耳の位置（鼻先からの割合） | 0.575 |
| 首の幅 / 頭の最大幅 | 0.62（上が細く、付け根が少し太い。なめらかな楕円柱） |
| 首の厚み / 首の幅 | 0.80（画面で） |
| 肩線 | 首の付け根から肩先へ 16.5° 下がる |

- **縦の位置の決め方：**
  - 目 0.50・三等分・頭頂→生え際 0.30 は、同時には満たせません。0.30 だと眉が 0.53 になり、目より下になるためです。
  - そこで、どれも ±10% に入る値にしています。
- **頭の形の作り方：**
  - 元の頭のメッシュは粗いので、頭の面を 1 回細かく分けます。
  - そのうえで、高さごとの横幅を目標の輪郭に合わせて変形します（`shape_head`）。
- **首の付け根の直し方：**
  - 元のメッシュは、首の横の高い頂点が肩と直接つながっています。正面から見ると、あごの下から急な坂（首がない形）になります。
  - その頂点を肩線の高さまで下げ、重みを首と胸に付け替えています（`fix_trap_apex`）。
- **首の見かけの長さ：**
  - あご先→襟ぐり（正面の真ん中）が頭の高さの約 0.33 倍です（見た目を優先して短め）。
  - ゲームの `render.c` の `SKIN_NECK_K`（0.46）と、襟の高さ `COLLAR_T`（0.45）で決めています。
- **首の表面：**
  - 元の首の縦の筋（筋肉の出っ張り）は取って、目標の楕円柱の上に頂点を並べ直しています（`smooth_neck`）。耳の下（頭の付け根より少し上）までつなげます。
  - 元のモデルの決まった法線は消して形から計算し直し、首の頂点の法線は楕円の外向きにそろえています（`neck_normals`）。首の三角は細長く不ぞろいなので、こうしないとくさび形の明暗が出ます。
- **実測で決めた値：** いくつかの数値は、ゲームの画面を真正面と真横からほぼ平行投影で撮って、ピクセルで測って決めています。
  - `CHIN_CORNER`・`JAW_CAL`・`HAIR_TOP`・`HAIR_SIDE`・`HAIR_BACK` など
  - 測るときは、鼻・耳・髪・顔の部品を決まった色にしています。

## 骨の対応表（ゲームの関節 → 骨）
ゲームは、決まった名前の骨に、コードが計算した関節の位置・向きを毎フレーム書き込みます。表は `body_model.c` の `SKMAP` です。

| 骨（決まった名前） | 頭の関節 → しっぽの関節 | ねじれの基準 |
|---|---|---|
| hips | 腰の中心 → ウエスト | 腰の前 |
| spine1 / spine2 / spine3 | ウエスト → 背骨の中ほど → 胸 → 首の付け根 | 腰と胸の前の間 |
| neck / head | 首の付け根 → 頭の付け根 → 頭の上 | 胸の前・顔の前 |
| clavicle.R/.L | 胸の上の真ん中 → 肩 | 胸の前 |
| upperarm / forearm / hand | 肩 → 肘 → 手首 → 手の先 | 肘が曲がる側 |
| thigh / shin | 股関節 → 膝 → 足首 | 後ろ |
| foot / toe | 足首 → 足の付け根 → つま先 | 上 |

- **元の骨の名前の探し方：** `tools/make_skinned_players.py` の `BONE_ALIASES` にある候補から探します。Rigify（`DEF-upper_arm.L`）・Mixamo（`mixamorig:LeftArm`）・UE（`upperarm_l`）に対応しています。見つからない骨があれば、その名前をここに足してください。
- **肘と膝：** 1 軸のヒンジで、0〜150° に制限しています（`render.c` の `ElbowIK`）。肘は体の下後方、膝は前に曲がります。

## ライセンスの確かめ方（モデルを差し替えるとき）
1. 素材のページと、ダウンロードした中の `License.txt` などの両方で、ライセンスを確かめます。
2. 「商用利用できる」「改変できる」「ゲームに入れて配れる」の 3 つがそろっているかを見ます。CC0・CC BY は大丈夫です。CC BY-NC（非商用）・CC BY-ND（改変禁止）・「個人利用のみ」は使えません。
3. CC BY のときは、作者名・作品名・ライセンスを `dist_files/CREDITS.txt` に書きます。
4. `SOURCE.txt` を、新しいモデルの出どころに書き換えます。
