# 3D テニス（raylib / C）

コンセプト：**打点と球種がちゃんと結果に効く、球足の速いリアル系テニス**

## ステップ3：打点システム（いまここ）

球出しマシンが相手コートからランダムに球を出す。動いて、溜めて、タイミングよく離して打ち返す。

打点は3つの要素で評価し、掛け算したものが「質」（0〜100%）になる。

| 要素 | 理想 | ずれると |
|---|---|---|
| タイミング | 体より 40cm 前 | 早い→引っ張る（フォアなら左）、遅い→流れる |
| 体からの距離 | 85cm | 近い＝詰まる、遠い＝伸びきる |
| 高さ | 球種ごとに違う（フラット 1.2m / トップ 1.0m / スライス 0.75m） | その球種が打ちにくい高さ |

質が悪いと、球速と回転が落ち、狙いが左右・上下に散らばる。

### 来た球の勢い

返球の速さ ＝ 0.4 × 来た球の速さ ＋ 1.4 × ラケットの速さ（実際のラケットの反発に近い式）。

- 溜めなしで離すとコンパクトなスイング（ブロック）。タイミングの許容幅が広く、来た球の勢いで返す
- 大きく溜めるほどタイミングがシビア
- ノーバウンドで打つとボレー。自分の力は 4 割しか乗らないが、タイミングの許容幅は広い
- ラケット面のずれは、跳ね返る成分では 2 倍効く。速い球ほど狙いが狂い、深さもばらつく
- 芯を外したときのラケットのねじれ：45km/h を超える重い球ほど、打点のずれが大きく響く（速いファーストサーブが決まる理由）
- キー入力は 1/60 秒単位でしか取れないので、離したフレームの間で一番いい瞬間を採用する
- 前に踏み込みながら打つと（W を押しながら）、球が重くなり（最大 +12km/h）、ぶれが減る（最大 35%）。下がりながらだとぶれが増える

### 速さの違い

| 球 | 打ち出し | 自分が打つ瞬間 | 届くまで |
|---|---|---|---|
| プロのラリー | 120 km/h | 約 53 km/h | 約 1.0 秒 |
| ファーストサーブ | 200 km/h | 約 93 km/h | 約 0.6 秒 |

同じ打点のずれでも、速い球ほど狙いが大きく狂う。だからサーブは決まり、まっすぐ当てて踏み込めば返る。

## サーブ（G でモード切替）

- A/D で立ち位置（センターマークの片側だけ）
- L=フラット / K=スライス / J=キック を押すとトス、溜めて、離した瞬間に打つ
- 理想の打点は落ちてきて 2.8m。それより 20cm 以上高いうちに振ると空振り（フォルト）。低いと物理的に入りにくい
- トスは毎回少しぶれる。悪いトスは押しっぱなしで見送れる（1.2m まで落ちるとやり直し、ペナルティなし）
- 離した瞬間の A/D でコース（ボックスの左右の端）、なしでボディ。W/S で深さ
- 溜めるほど速いが、ぶれも大きい
- 回転：スライスは横回転で曲がる。キックはトップスピン＋進行方向まわりの回転で、高く跳ねて横に跳ねる

| サーブ | 速さ | 特徴 |
|---|---|---|
| フラット | 150〜215 km/h | 一番速いが、ネットの余裕 15〜20cm |
| スライス | 140〜190 km/h | 空中で外へ曲がる。ワイドが効く |
| キック | 120〜170 km/h | ネットの余裕 45〜50cm。高く跳ねて横に跳ねる。セカンド向き |
画面の HUD に、どの要素が悪かったかを毎回表示する。

### 操作

| キー | 動作 |
|---|---|
| WASD | 移動。打った瞬間に押している方向がコースになる（A=左, D=右, W=深く, S=短く） |
| J / K / L（押して離す） | トップスピン / スライス / フラット。離した瞬間にスイング |
| Shift + J / K / L | トップスピンロブ / ドロップ / スライスロブ |
| F | すぐに次の球を出す |
| G | 練習モード切替：ラリー / リターン（マシンのサーブ） / サーブ（自分で打つ） |
| V | ラリーの球出しの速さ：PRO（105〜140km/h）/ CLUB（80〜110km/h） |
| R | バウンドテスト（2.54m から落とす） |
| C | カメラ切替 |
| T | スロー |

| 球種 | 球速 | 回転 |
|---|---|---|
| フラット | 90〜190 km/h | 500〜900 rpm |
| トップスピン | 70〜150 km/h | 1800〜3200 rpm |
| スライス | 60〜120 km/h | 逆回転 1200〜2200 rpm |
| トップスピンロブ | 60〜90 km/h | 2000〜3500 rpm（攻めのロブ。溜めるほど低く速い） |
| スライスロブ | 50〜65 km/h | 逆回転 800〜1500 rpm（守りのロブ。同じ着地点でも高い方の弾道） |
| ドロップ | 届く速さを自動で決める | 逆回転 1500〜2500 rpm（打ち出し角 28° 固定。溜めは回転量に効く） |

### ビルド

```sh
make
./tennis
```
