# 3D テニス（raylib / C）

コンセプト：**打点と球種がちゃんと結果に効く、球足の速いリアル系テニス**

## ステップ2：回転と空気抵抗、球種の打ち分け（いまここ）

- 空気抵抗（速さの2乗に比例）とマグヌス効果（回転で球が曲がる力）
- バウンドは接地点の「滑り」を摩擦が打ち消すモデル。回転によって跳ね方が変わる
- 反発係数 0.77 → 空気抵抗込みで 2.54m から落として 1.40m 跳ねる（ITF 規格 1.35〜1.47m）
- 狙った地点に落ちる打ち出し角を、回転込みの物理シミュレーションで逆算
- HUD にネット上の余裕（Net clearance）を表示

| 球種 | 球速 | 回転 |
|---|---|---|
| フラット | 90〜190 km/h | 500〜900 rpm |
| トップスピン | 70〜150 km/h | 1800〜3200 rpm |
| スライス | 60〜120 km/h | 逆回転 1200〜2200 rpm |

### 操作

| キー | 動作 |
|---|---|
| J（押して離す） | トップスピン。長く押すほど速く、回転も多い |
| K（押して離す） | スライス |
| L（押して離す） | フラット |
| 矢印キー | 狙う位置 |
| R | バウンドテスト（2.54m から落とす） |
| C | カメラ切替（後方 / 真横 / 追従） |
| T | スロー |

### ビルド

```sh
make
./tennis
```
