# 3D テニス（raylib / C）

コンセプト：**打点と球種がちゃんと結果に効く、球足の速いリアル系テニス**

## ステップ1：重力とバウンド（いまここ）

- コートは ITF 規格の実寸（メートル単位）。ネットは中央 0.914m → ポスト 1.07m のたるみ付き
- 物理は 1/240 秒の固定ステップ。速い球でもネットや地面をすり抜けない
- 反発係数 0.75 → 2.54m から落とすと 1.44m 跳ねる（ITF 規格 1.35〜1.47m に収まる）
- 狙った地点に落ちる打ち出し角を、物理シミュレーションで逆算（空気抵抗・回転を足してもそのまま使える）
- ボールの影と軌跡を表示

### 操作

| キー | 動作 |
|---|---|
| SPACE | 打つ |
| ↑ / ↓ | 球速 |
| ← / → , W / S | 狙う位置 |
| R | バウンドテスト（2.54m から落とす） |
| C | カメラ切替（後方 / 真横 / 追従） |
| T | スロー |

### ビルド

```sh
make
./tennis
```
